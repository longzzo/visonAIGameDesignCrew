# 마스터 GDD — 기존 드쫀슬 기획 추가

> Vision Engine이 관리하는 마스터 게임 디자인 문서. PM 디렉터가 각 전문 에이전트의 산출물을 이 문서에 통합한다.

## 1. 개요

**"던전에서 캐고, 김치를 담그고, 주막에서 팔아라!"**

- 가제: 슬라임 김치 · 장르: 경영 시뮬레이션 + 던전 파밍 + 요리 제작 · 플랫폼: **PC (Steam)**
- 타겟: 경영 시뮬 & 캐주얼 던전 크롤러 유저, 유머러스한 세계관을 선호하는 10~30대
- 핵심 루프: 식재료의 탑 탐색 → 재료 획득 → (시장 보충) → 김치 제작·발효 → 주막 장사 → 정산 → 다음 날
- 이번 확장: **시장 시스템** — 요리 재료 매대 · 상위 재료 로테이션 매대 · 레시피 뽑기(인게임 골드 재화) · 보스 김치 의뢰(스토리 키포인트)
- 레시피 뽑기는 기본적으로 인게임 골드 전용 — 현금 연동 여부는 수익모델에서 별도 결정(그 경우 확률형 규제 고지 적용)

> 🔎 검증 노트: 대표 통합본이 "모바일 F2P 동시 출시"로 원본 기획(PC Steam)과 어긋나 오너 대리 검증에서 재작성함.

## 2. 세계관·스토리

### 세계관·스토리 퓨전 판타지 조선의 시장 거리엔, 김치 재료 매대(3번)가 빛나고, 뽑기 상인은 “레시피의 운명”을 판매한다. 슬라임은 탑에서 캐낸 재료를 시장에서 절대 판매하거나 구매할 수 없으며, 오직 시장에서 구매한 재료로만 조리한다. 만드라고라 배추는 매대 3번에서 부글부글 노래하며 빛나고, 플레이어는 오디오와 아이콘 반짝임으로 그 신성함을 인지한다. 누나의 국자 소리에 “옙!” 하고 뛰어가며, 슬라임의 허세는 진심, 폭력은 사랑, 뽑기로 얻은 레시피는 법으로 금지된 희망이다. 주인공은 발효 계급 사회의 최하층 낙제생으로, 김치 유산균에 각성해 침투 선발대 요리사로 좌천된 ‘노예 겸 동업자’다. 보스 김치 의뢰는 그 성장의 증표다: **챕터 1 — 초원의 빛나는 김치** *탑 1~15층 | 중간 보스: 버섯슬라임 왕 (HP 800, 드랍률 12%) | 특수 재료: 광합성 배추 | 전설 김치: 빛나는 김치* > “이 배추를 얻으려면, 버섯슬라임 왕의 춤을 따라야 한다. 화련의 국자가 3번 흔들리며, 네 손이 떨린다.” **챕터 2 — 불의 탑, 타는 희망** *탑 16~30층 | 중간 보스: 화염슬라임 수호자 (HP 1,500, 드랍률 8%) | 특수 재료: 불꽃 고춧가루 | 전설 김치: 타오르는 김치* > “이 고춧가루를 얻으려면, 불길 속에서 3초 동안 눈을 감아야 한다. 화련의 국자가 3번 흔들리며, 네 손이 떨린다.” **챕터 3 — 얼음의 눈물** *탑 31~45층 | 중간 보스: 냉기슬라임 왕비 (HP 2,200, 드랍률 6%) | 특수 재료: 얼어붙은 마늘 | 전설 김치: 눈송이 김치* > “이 마늘을 얻으려면, 눈보라 속에서 10초 동안 울음을 참아야 한다. 화련의 국자가 3번 흔들리며, 네 손이 떨린다.” **챕터 4 — 발효의 정점** *탑 46~50층 (숨겨진 층) | 중간 보스: 유산균의 그림자 | 특수 재료: 생명의 점액 | 전설 김치: 영원한 김치* > “이 점액을 얻으려면, 네가 가장 두려워한 기억을 김치통에 담아야 한다. 화련의 국자가 3번 흔들리며, 네 손이 떨린다.” *모든 보스 스탯·드랍률은 밸런스 시트로 위임. 전설 김치는 레시피 뽑기 미출현, 시장 판매 금지.*

## 3. 게임플레이

### 게임플레이
### 코어 루프 식재료의 탑 탐색 → 몬스터 처치 & 재료 획득 → 주막 진입 → 김치 제작 → 손님 대응 → 정산 → 다음 날로 전환 → 탑 선택 재진입
### 핵심 메커니크
1. **김치 유산균 발효** — 메인+매운+포인트 재료 조합으로 12가지 김치 생성, 각각 고유한 손님 만족도(50~100점)와 가격(30~100골드) 부여.
2. **석상 발효 스테이지** — 5층마다 황금 석상 선택 시, 김치 품질(단맛/풍미) 영구 +1계층 상승 → 고급 레시피 해금 및 가격 +20% 유도.
3. **시장 시스템** — 주막 외부 거리(PM12~PM6)에 3층 매대 배치: ``` [주막 문] → [기본재료 매대] → [로테이션 매대] → [뽑기 상인] → [의뢰 게시판] → [주막 복귀] ```
- **기본재료 매대**: 부침가루(5골드), 식용유(3골드), 파(2골드) — 요리 연구와 연동.
- **로테이션 매대**: 매일 1종 희귀 재료(홍합/산딸기/천연염색 고춧가루 등) 출현, 1일 1회 구매 제한, 확률 25%.
- **뽑기 상인**: 1회 뽑기 = 50골드, 12가지 레시피 확률: 메인(50%) + 매운(30%) + 포인트(20%). 석상 +1 시 고급 레시피 확률 1.5배 상승. 중복 레시피는 자동 보존.
- **K-Games 고지**: “뽑기 확률은 게임 내에서 공개되며, 구매는 실화폐와 연동되지 않습니다.”
### 세션 설계 한 세션 = 1일(약 12분 실제 시간):
- 아침(5분): 탑 탐색(AM6~PM12, 300초 게임타임)
- 점심(5분): 주막 운영(PM12~AM2, 300초 게임타임, 배속 연동)
- 저녁(2분): 정산 + 시장 방문(50초) + 다음 날 선택(자동 세이브, UI 클릭 2~3번) → 리듬: 긴장(탐색) → 전략적 운영(배속 활용) → 성취감(품질 상승) → 탐색 유도(시장 랜덤 재료)
### 리스크 **리스크**: 10일차 이후 손님 유입 패턴 정체 **대비책**: 발효 품질 +3 이상일 때, 매 3일마다 특수 손님(김치 마스터) 등장 → 고가 주문(150골드) + 스토리 전개 유도.

## 4. 시스템

> 🔎 검증 노트: 회의 중 수정본이 게이트웨이 타임아웃으로 유실되어, 교차검토 직전 초안을 복원함 (밸런스 검토 의견은 밸런스 섹션에 반영됨).

### 시스템 1. **성장 축**  
- 레벨: 10단계 (1일당 1레벨, 최대 10일) → 전투력 기반 탐색 속도  
- 발효 레벨: 50단계 (김치 품질 향상 시 +1) → 전투력 = Lv × 1.2^(발효레벨/10)  
- 장비: 장독대 3단계 업그레이드 (매 3일 해금) → 발효 속도/용량 증가  
- 스킬: 김치 레시피 5종 해금 (매 2일 1개) → 재료 조합 다양화  
- 수집: 식재료 탑 층별 드랍 (희귀도 차등) → 발효 레벨 상승 자극  
*왜 존재하는가?* 성장의 끝을 없애고, 전투와 발효를 수학적으로 연결해 지속적 동기 부여.

### 시스템 2. **재화 표**  
- 골드: 정산 씬 (손님 결제) → 장비/식재료/시장 구매, 병목: 초기 자동화 부족  
- 발효 포인트: 김치 제작 성공 시 획득 → 발효 레벨 상승, 병목: 해금 지연  
- 수분: 탑 탐색 시 소모, 층 도착 시 +10% 회복, 김치 1개 소비 시 +30% 회복, 병목: 해금 전 무력화  
- 체력: 탑 탐색 시 감소 → 기절 시 주막 진입, 병목: 회복 아이템 미해금  
*왜 존재하는가?* 모든 자원은 발효와 탐색의 순환을 유지하기 위해 설계됨.

### 시스템 3. **콘텐츠 진행 구조**  
- 챕터: 12일간의 날짜 (1일 = 1챕터)  
- 시즌: 3개 (초기: 기본 김치, 중반: 특수 재료, 후반: 직원/이벤트)  
- 스테이지: 식재료의 탑 10층 (5층마다 황금 석상 해금)  
- 이벤트: 매 3일 1회 (특수 손님, 동료 슬라임 등장)  
*왜 존재하는가?* 매일 새로운 목표를 제공하며, 발효 레벨 상승이 콘텐츠 해금과 직결.

### 시스템 4. **시스템 의존 다이어그램**  
레벨 ↑ → 전투력 ↑ → 탐색 속도 ↑ → 식재료 수집 ↑ → 김치 품질 ↑ → 발효 레벨 ↑ → 전투력 ↑↑  
수분 ↓ → 층 도착 시 +10% 회복 + 김치 소비 시 +30% 회복 → 탐사 지속성 ↑ → 발효 레벨 ↑  
시장 구매 재료 → 다음 날 이월 → 발효 재료 확보 → 레시피 해금 자극  
*왜 존재하는가?* 모든 시스템이 발효 레벨을 중심으로 순환하며, 지루함을 수학적으로 차단한다.

### 시스템 5. **시장 시스템**  
- **위치**: 주막 외부 거리 (PM12~PM6), 주막 문 → 시장 → 주막 복귀 동선  
- **배치 (ASCII)**:  
```
[주막 문] → [재료 매대] — [로테이션 매대] — [뽑기 상인]  
              |               |               |  
          [부침가루, 식용유] [상급 젓갈, 양념] [레시피 뽑기: 50골드/1회]  
              |               |               |  
          [간단 요리 재료]   [1일 1회 한정]   [확률: N=70%, R=25%, SR=5%]  
```  
- **요리 재료 매대**: 부침가루, 식용유, 파 등 → 아궁이 요리 연구와 연동 (기존 시스템 유지)  
- **로테이션 매대**: 상급 젓갈, 특제 양념 등 → 매일 3종 랜덤, 1일 1회 구매 제한  
- **레시피 뽑기**: 뽑기 상인 존재, 50골드/1회, 확률 N(70%)·R(25%)·SR(5%), 중복 시 보상 전환 (발효 포인트 100), K-Games 규제 고지: “확률형 아이템은 공개되며, 구매 시 자동으로 확률 정보가 표시됩니다.”  
*왜 존재하는가?* 시장은 발효의 자원 흐름을 확장하고, 뽑기로 인한 의도적 긴장감을 통해 지루함을 차단한다.

## 5. UI/UX

### UI/UX (최종본)
#### 화면 목록과 1순위 정보
1. **탑 선택 씬** — 탑 종류 및 층 선택 버튼 (가장 큰 버튼: “탐험 시작”)
2. **식재료의 탑** — 체력/수분(잔여량)/층 수/시계 UI (상단 고정, 클릭 가능 아이템 칸)
3. **주막(장사 준비)** — [장사 시작] 버튼 (중앙 하단, 크고 붉은색), 수분(잔여량) 표시 (바 아래), **시장 진입 버튼** (오른쪽 상단, 작고 흰색 테두리, “시장”)
4. **주막(장사 중)** — 손님 주문 팝업 (상단 중앙), 발효 진행 바 (오른쪽, 소모량 시각화)
5. **시장 씬** — 매대 3개 (좌: 요리 재료, 중: 상위 재료 로테이션, 우: 레시피 뽑기), **복귀 버튼** (하단 중앙, 주막 문 아이콘), 골드 잔액 (상단 고정)
6. **정산 씬** — [다음 날로] 버튼 (하단 중앙, 금색 배경), 수분(잔여량) 및 발효 효율 표시, **이월 재료: [파 3, 특제 양념 1]** (하단 작은 텍스트, 회색)
#### 핵심 플로우 탑 선택 → 식재료의 탑 (AM6~PM12) → 주막(장사 준비) (PM12~PM6) → **시장 진입** (PM6~PM7) → 주막(장사) (PM7~AM2) → 정산 → 탑 선택
#### 온보딩 5단계
1. **탑 선택** — “탐험 시작” 버튼으로 첫 층 진입
2. **식재료의 탑** — 수분(잔여량) 획득 → 주막 발효 속도에 직접 반영
3. **주막 준비** — 수분(잔여량) 확인 후 [장사 시작] 클릭
4. **시장 진입** — 상위 재료 매대에서 “1일 1회” 아이콘 확인 후 구매, 레시피 뽑기에서 확률 표시 확인
5. **정산** — 수분(잔여량) 저장량과 발효 효율을 기반으로 다음 날 전략 수립
#### 플랫폼별 조작 유의점
- **PC (마우스)** — 이동: WASD, 상호작용: 좌클릭, 시장 매대: 마우스 오버로 재료 설명 및 제한 표시
- **모바일 (터치)** — 조이스틱으로 이동, 터치로 상호작용, 시장 매대: 터치로 구매, “1일 1회” 아이콘은 빨간 점으로 강조
- **모든 플랫폼** — 수분(잔여량): 투명 청색 바, 발효 진행 바: 불투명 주황색 바, **시장 진입 버튼: 흰색 테두리 + 1px 흐림 효과로 구분**
#### 시장 레벨디자인·맵 배치 초안 ``` [주막 문] │ ▼ [요리 재료 매대] — 부침가루, 식용유, 파, 마늘 (골드 50~150) [상위 재료 매대] — 상급 젓갈, 특제 양념, 고추가루(희귀) (1일 1회, ⭐) [레시피 뽑기] — 10골드/회, 94% 일반, 5% 희귀, 1% 비밀 레시피 (확률 표시) │ ▼ [복귀 버튼] — 주막 문 아이콘, 클릭 시 PM6~PM7 시간 차감 ```
#### 상위 재료 로테이션 규칙
- 매일 자정 갱신, 3가지 품목 중 1개는 희귀 재료 (예: 고급 젓갈, 발효 효소)
- 희귀 재료는 전투 보상으로도 획득 불가, 시장에서만 구매 가능
- 구매 시 “1일 1회” 경고 팝업 표시 (K-Games 규제 대응)
#### 레시피 뽑기 시스템
- 뽑기 상인: 시장 우측 매대, 10골드/회, 최대 10회/일
- 확률: 일반(94%), 희귀(5%), 비밀 레시피(1%) — 비밀 레시피는 100회 시도 시 100% 보장
- 중복 레시피: 자동 변환 → 발효 효율 +10% (최대 +50%)
- K-Games 고지: 뽑기 확률을 매번 진입 시 하단 텍스트로 명시 (“확률: 일반 94% / 희귀 5% / 비밀 레시피 1%”) > *모든 수치는 가안. 밸런싱 수치 시트로 전달 예정.*

## 6. 밸런스

### 밸런스 디자인: 슬라임 김치 (최종본) **1. 기준 수치 표**

| 레벨 | HP | 공격력 | 수분 | 골드/일 |
|---|---|---|---|---|
| 1 | 100 | 10 | 100 | 50 |
| 10 | 300 | 38 | 180 | 200 |
| 30 | 900 | 110 | 300 | 600 |
| 50 | 1800 | 180 | 450 | 1200 |

**2. 성장 곡선 공식**
- HP = 100 × 1.07^(Lv-1)
- 공격력 = 10 + 8×⌊(Lv-1)/5⌋ + 2×((Lv-1)%5)
- 수분 = 100 + 8×Lv
- 골드/일 = 50 × 1.1^(Lv-1)
**3. 난이도 곡선**
- 레벨 1~10: 몬스터 DPM 800 이하 → 안정적 성장
- 레벨 11~30: 몬스터 DPM 1200~2000 → 수분 관리 필수
- 레벨 31~50: 몬스터 DPM 2500+ → 고급 재료 확보가 생존 조건
**4. 붕괴 시나리오** **파워 크리프**: 레벨 40 이후 배속 8배속 + 자동화로 김치 생산량 폭증 → 골드 수입이 몬스터 HP 성장보다 3배 빠름 → 던전 탐색 의지 상실. **방지책**: 만드라고라 배추 1개 확보 시 김치 품질 +30% → 손님 만족도 급등, 수익 2.5배 상승 → 탑 탐색이 수익 극대화의 유일한 수단으로 강화.
**5. 시장 시스템 (수정)**
- **매대 배치**: 삼각형 동선 — [주막문] → [부침가루] → [특제젓갈] → [뽑기상인] → [의뢰판] → [주막문]. 선택적 탐색 유도.
- **로테이션 매대**: 하루 1개 상위 재료 → 1일 1회 구매 제한, 매일 랜덤 교체.
- **레시피 뽑기**: 1회 50골드, 확률: 일반 70% / 희귀 25% / 전설 5%. 중복 시 → 잠재 레시피 티켓(1장) 지급. K-Games 규제 준수: 확률 공개, 구매 제한 10회/일.
- **재료 이월**: 시장 구매 재료는 다음 날 이월 가능, 제작/영업 시간은 시장 사용 시간만큼 차감. *모든 수치는 밸런싱 수치 시트로 넘긴다.*

## 9. 기술

### 기술 명세: 슬라임 김치 (최종본)
1. **아키텍처**: 씬 기반 FSM 유지. `MarketManager` 추가, 탑/주막/시장 전환은 상태 이벤트로 처리.
2. **데이터 흐름**: `MarketInventory` ScriptableObject로 1일 3종 로테이션 및 1회 구매 제한 정의. 재료 이월은 `DailyStorage`에 골드 기반 잔여량 저장.
3. **컴포넌트 설계**: `MarketVendor`는 뽑기 확률을 일반 40% / 희귀 35% / 전설 25%로 조정. 중복 레시피는 자동 해금.
4. **결합 방식**: 시장 사용 시간은 주막 영업 시간에서 1:1 차감. 수분 0 시 ‘긴급 재료 구매’ 옵션 활성화로 선택권 보장.
5. **성능**: 로테이션은 `System.Random` + Seed(매일 00:00 재시작). K-Games 규제 준수: 확률 UI 명시, 3단계 확인 팝업.
6. **밸런싱**: 모든 수치는 가안이며, 밸런스 시트에 전달됨.
