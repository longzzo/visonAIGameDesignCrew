## 2. 세계관·스토리

### 세계관·스토리 퓨전 판타지 조선의 시장 거리엔, 김치 재료 매대(3번)가 빛나고, 뽑기 상인은 “레시피의 운명”을 판매한다. 슬라임은 탑에서 캐낸 재료를 시장에서 절대 판매하거나 구매할 수 없으며, 오직 시장에서 구매한 재료로만 조리한다. 만드라고라 배추는 매대 3번에서 부글부글 노래하며 빛나고, 플레이어는 오디오와 아이콘 반짝임으로 그 신성함을 인지한다. 누나의 국자 소리에 “옙!” 하고 뛰어가며, 슬라임의 허세는 진심, 폭력은 사랑, 뽑기로 얻은 레시피는 법으로 금지된 희망이다.

## 3. 게임플레이

### 게임플레이
### 코어 루프 식재료의 탑 탐색 → 몬스터 처치 & 재료 획득 → 주막 진입 → 김치 제작 → 손님 대응 → 정산 → 다음 날로 전환 → 탑 선택 재진입
### 핵심 메커니크
1. **김치 유산균 발효** — 메인+매운+포인트 재료 조합으로 12가지 김치 생성, 각각 고유한 손님 만족도(50~100점)와 가격(30~100골드) 부여.
2. **석상 발효 스테이지** — 5층마다 황금 석상 선택 시, 김치 품질(단맛/풍미) 영구 +1계층 상승 → 고급 레시피 해금 및 가격 +20% 유도.
3. **시장 시스템** — 주막 외부 거리(PM12~PM6)에 3층 매대 배치: ``` [주막 문] → [기본재료 매대] → [로테이션 매대] → [뽑기 상인] → [의뢰 게시판] → [주막 복귀] ```
- **기본재료 매대**: 부침가루(5골드), 식용유(3골드), 파(2골드) — 요리 연구와 연동.
- **로테이션 매대**: 매일 1종 희귀 재료(홍합/산딸기/천연염색 고춧가루 등) 출현, 1일 1회 구매 제한, 확률 25%.
- **뽑기 상인**: 1회 뽑기 = 50골드, 12가지 레시피 확률: 메인(50%) + 매운(30%) + 포인트(20%). 석상 +1 시 고급 레시피 확률 1.5배 상승. 중복 레시피는 자동 보존.
- **K-Games 고지**: “뽑기 확률은 게임 내에서 공개되며, 구매는 실화폐와 연동되지 않습니다.”
### 세션 설계 한 세션 = 1일(약 12분 실제 시간):
- 아침(5분): 탑 탐색(AM6~PM12, 300초 게임타임)
- 점심(5분): 주막 운영(PM12~AM2, 300초 게임타임, 배속 연동)
- 저녁(2분): 정산 + 시장 방문(50초) + 다음 날 선택(자동 세이브, UI 클릭 2~3번) → 리듬: 긴장(탐색) → 전략적 운영(배속 활용) → 성취감(품질 상승) → 탐색 유도(시장 랜덤 재료)
### 리스크 **리스크**: 10일차 이후 손님 유입 패턴 정체 **대비책**: 발효 품질 +3 이상일 때, 매 3일마다 특수 손님(김치 마스터) 등장 → 고가 주문(150골드) + 스토리 전개 유도.

6. **정산 씬** — [다음 날로] 버튼 (하단 중앙, 금색 배경), 수분(잔여량) 및 발효 효율 표시, **이월 재료: [파 3, 특제 양념 1]** (하단 작은 텍스트, 회색)
#### 핵심 플로우 탑 선택 → 식재료의 탑 (AM6~PM12) → 주막(장사 준비) (PM12~PM6) → **시장 진입** (PM6~PM7) → 주막(장사) (PM7~AM2) → 정산 → 탑 선택
#### 온보딩 5단계
1. **탑 선택** — “탐험 시작” 버튼으로 첫 층 진입
2. **식재료의 탑** — 수분(잔여량) 획득 → 주막 발효 속도에 직접 반영
3. **주막 준비** — 수분(잔여량) 확인 후 [장사 시작] 클릭
4. **시장 진입** — 상위 재료 매대에서 “1일 1회” 아이콘 확인 후 구매, 레시피 뽑기에서 확률 표시 확인
5. **정산** — 수분(잔여량) 저장량과 발효 효율을 기반으로 다음 날 전략 수립
#### 플랫폼별 조작 유의점
- **PC (마우스)** — 이동: WASD, 상호작용: 좌클릭, 시장 매대: 마우스 오버로 재료 설명 및 제한 표시
- **모바일 (터치)** — 조이스틱으로 이동, 터치로 상호작용, 시장 매대: 터치로 구매, “1일 1회” 아이콘은 빨간 점으로 강조
- **모든 플랫폼** — 수분(잔여량): 투명 청색 바, 발효 진행 바: 불투명 주황색 바, **시장 진입 버튼: 흰색 테두리 + 1px 흐림 효과로 구분**
#### 시장 레벨디자인·맵 배치 초안 ``` [주막 문] │ ▼ [요리 재료 매대] — 부침가루, 식용유, 파, 마늘 (골드 50~150) [상위 재료 매대] — 상급 젓갈, 특제 양념, 고추가루(희귀) (1일 1회, ⭐) [레시피 뽑기] — 10골드/회, 94% 일반, 5% 희귀, 1% 비밀 레시피 (확률 표시) │ ▼ [복귀 버튼] — 주막 문 아이콘, 클릭 시 PM6~PM7 시간 차감 ```
#### 상위 재료 로테이션 규칙
- 매일 자정 갱신, 3가지 품목 중 1개는 희귀 재료 (예: 고급 젓갈, 발효 효소)
- 희귀 재료는 전투 보상으로도 획득 불가, 시장에서만 구매 가능
- 구매 시 “1일 1회” 경고 팝업 표시 (K-Games 규제 대응)
#### 레시피 뽑기 시스템
- 뽑기 상인: 시장 우측 매대, 10골드/회, 최대 10회/일
- 확률: 일반(94%), 희귀(5%), 비밀 레시피(1%) — 비밀 레시피는 100회 시도 시 100% 보장
- 중복 레시피: 자동 변환 → 발효 효율 +10% (최대 +50%)
- K-Games 고지: 뽑기 확률을 매번 진입 시 하단 텍스트로 명시 (“확률: 일반 94% / 희귀 5% / 비밀 레시피 1%”) > *모든 수치는 가안. 밸런싱 수치 시트로 전달 예정.*

## 6. 밸런스

### 밸런스 디자인: 슬라임 김치 **1. 기준 수치 표**

| 레벨 | HP | 공격력 | 수분 | 골드/일 |
|---|---|---|---|---|
| 1 | 100 | 10 | 100 | 50 |
| 10 | 300 | 38 | 180 | 200 |
| 30 | 900 | 110 | 300 | 600 |
| 50 | 1800 | 180 | 450 | 1200 |

**2. 성장 곡선 공식**
- HP = 100 × 1.07^(Lv-1)
- 공격력 = 10 + 8×⌊(Lv-1)/5⌋ + 2×((Lv-1)%5)
- 수분 = 100 + 8×Lv
- 골드/일 = 50 × 1.1^(Lv-1)
**3. 난이도 곡선**
- 레벨 1~10: 몬스터 DPM 800 이하 → 안정적 성장
- 레벨 11~30: 몬스터 DPM 1200~2000 → 수분 관리 필수
- 레벨 31~50: 몬스터 DPM 2500+ → 고급 재료 확보가 생존 조건
**4. 붕괴 시나리오** **파워 크리프**: 레벨 40 이후 배속 8배속 + 자동화로 김치 생산량 폭증 → 골드 수입이 몬스터 HP 성장보다 3배 빠름 → 던전 탐색 의지 상실. **방지책**: 만드라고라 배추 1개 확보 시 김치 품질 +30% → 손님 만족도 급등, 수익 2.5배 상승 → 탑 탐색이 수익 극대화의 유일한 수단으로 강화.

## 7. 수익모델

### 추천 BM: F2P + 가챠 + 광고 하이브리드 (차선: 유료 본편 + 패스)
**1. 추천 BM** **F2P + 가챠 + 광고 하이브리드** — 가챠는 오직 희귀 재료(만드라고라 배추 등)만 제공, 성장은 시간과 노동으로만 이뤄져 F2P 유저의 지속 가능성을 보장. **차선: 유료 본편 + 패스** — 1만원에 본편 구매 + 월 3,000원 ‘김치 패스’로 매주 특별 재료 + 슬라임 코스튬. *선택 근거:* 가챠는 ‘각성’ 스토리와 연결되나, 성장은 공정한 노동 기반으로 설계.
**2. 과금 상품 구성표**

| 상품 | 가격대 | 구매 동기 |
|---|---|---|
| 희귀 김치 재료 박스 | 500원 | 전설 재료 확률 3.5%, 성장에 직접 영향 없음 |
| 발효 배속 해금 | 1,000원 | 주막 내 발효 속도 + 손님 주문 빈도 동시 8배 증가 → 전략적 자원 최적화 |
| 슬라임 코스튬 | 1,500원 | 귀여움 소비, 캐릭터 애정 반영 |
| 광고로 무료 재료 1회 | 0원 | 광고 시청 시 희귀 재료 1개 증정 |

**3. 첫 결제 유도 설계** **시점:** 5일차, 첫 ‘황금 석상’ 도달 후 **명분:** “이제부터는 김치의 진정한 맛을 알게 될 거야. 이 박스 없으면 영원히 ‘무능력 슬라임’일 뿐.” → 가챠 박스 10% 확률로 전설 유산균 발현 이벤트 트리거.
**4. 윤리·규제 리스크** 확률형 아이템 고지: “김치 레시피 박스의 희귀 재료 확률은 3.5%이며, 게임 내 재화로 구매 가능합니다.” — **K-Games 규제 기준 준수 필수**. *충돌 지점:* 배속은 자원 흐름 최적화로 작동하므로, F2P 유저의 시간 투자와 성장 간 공정한 균형 유지.

## 9. 기술

### 기술 명세: 슬라임 김치
1. **아키텍처**: 씬 기반 FSM으로 탑/주막/정산 전환. 각 씬은 독립적인 MonoBehaviour 기반 로직을 가짐.
2. **데이터 흐름**: ScriptableObject로 재료, 레시피, 스탯, 탑 테마 정의. 상태는 탑 관리자/주막 관리자로 분리된 별도 인스턴스가 관리.
3. **컴포넌트 설계**: 슬라임은 `SlimeCore` (발효), `SlimeCombat` (공격), `SlimeInventory` (인벤토리)로 분리. 화련은 `ChefAI` + `DialogueTrigger`.
4. **결합 방식**: 이벤트 시스템으로 수분 0 시 ‘발효 중단’ 효과 발동 → 플레이어가 회복 아이템 사용으로 탑 유지 또는 주막 전환 선택 가능. 씬 전환은 상태 전이 이벤트로 처리.
5. **성능**: 절차적 룸 생성은 Job System + Burst Compiler로 100ms 이내. 탑 뷰 카메라 추적은 Cinemachine + SmoothDamp.
