# 마스터 GDD — 기존 드쫀슬 기획 추가

> Vision Engine이 관리하는 마스터 게임 디자인 문서. PM 디렉터가 각 전문 에이전트의 산출물을 이 문서에 통합한다.

## 1. 개요

**"던전에서 캐고, 김치를 담그고, 주막에서 팔아라!"**

*   **가제:** 슬라임 김치
*   **장르:** 경영 시뮬레이션 + 던전 파밍 + 요리 제작
*   **플랫폼:** PC (Steam)
*   **타겟:** 경영 시뮬 & 캐주얼 던전 크롤러 유저, 유머러스한 "멀티버스 조선" 세계관을 선호하는 10~30대

**[핵심 루프]**
1.  **식재료의 탑 탐험:** 1~45층 (초원/불/얼음 테마별) 구간을 탐색하여 기본 식재료 채취 및 보스 특수 재료 (전설 김치용) 획득. *(챕터 4용 숨겨진 층 46~50층은 신설 가안 — 오너 미결)*
2.  **시장 및 의뢰 수주:** 주막 외부 거리 시장 (PM12~PM6) 에서 기본/상위 재료 구매 및 **보스 김치 의뢰** 수주 → 목표 보스 처치 및 재료 확보.
3.  **전설 김치 제작 → 주막 장사:** 특수 재료로 전설 김치 발효 및 판매, 정산 후 다음 날로 전환.

**[차별점]**
1.  **계급 성장 서사:** 발효 계급 사회 최하층 낙제생 (무능력) 이 김치 유산균으로 각성해 전설 장인으로 올라서는 스토리.
2.  **이원화 재료 시스템:** 던전 (파밍 전용/판매 불가) 과 시장 (구매/조리 전용) 의 물리적 격리로 전략적 자원 배분 심화.

**[산출물 충돌·조정 사항]**
*   **시장 격리:** 시장 매대에서 전설 김치 재료를 구매 불가 (의뢰 드랍 전용) 하도록 UI/UX 및 경제 설계의 조정이 필요함.
*   **보스 의뢰:** 스토리 키포인트인 챕터 구성 (정본 챕터 1~4) 은 탑 구간 테마 (초원/불/얼음) 와 연동되어 보스 드랍 → 전설 김치 → 챕터 개방 흐름으로 연동됨.

[위임] 시나리오: 보스 김치 의뢰 챕터별 구체적인 대사 및 과도기 스토리 작성
[위임] 밸런스: 보스 스탯 (HP/공격력) 및 특수 재료 드랍율 수치 시트 작성

## 3. 게임플레이

### 게임플레이
#### 코어 루프 식재료의 탑 탐색 → 몬스터 처치 & 재료 획득 → 주막 진입 → 김치 제작 → 손님 대응 → 정산 → 다음 날로 전환 → 탑 선택 재진입
#### 핵심 메커니크
1. **김치 유산균 발효** — 메인+매운+포인트 재료 조합으로 12가지 김치 생성, 각각 고유한 손님 만족도(50~100점)와 가격(30~100골드) 부여.
2. **석상 발효 스테이지** — 5층마다 황금 석상 선택 시, 김치 품질(단맛/풍미) **레벨당 1회만** 영구 +1계층 상승 → 전설 김치 레시피 확률 2배 증가.
3. **업그레이드 시스템** — 가게/직원/캐릭터/김치 4계열. 비용: cost(n) = 50 × 1.25^(n-1). Lv1~5: 50/62/78/98/122골드. 효과: 좌석 +1, 제작속도 +0.8%/HP +7%/수분보존 +2.5%/숙련도 +1/레시피연구 +0.8% 확률.
#### 세션 설계 한 세션 = 1일(약 12분 실제 시간):
- 아침(5분): 탑 탐색(AM6~PM12, 300초 게임타임)
- 점심(5분): 주막 운영(PM12~AM2, 300초 게임타임, 배속 연동)
- 저녁(2분): 정산 + 시장 방문(50초) + 다음 날 선택(자동 세이브, UI 클릭 2~3번) → 리듬: 긴장(탐색) → 전략적 운영(배속 활용) → 성취감(품질 상승) → 탐색 유도(시장 랜덤 재료/의뢰)
#### 리스크 **리스크**: 10일차 이후 손님 유입 패턴 정체 **대비책**: 발효 품질 +3 이상일 때, 매 3일마다 특수 손님(김치 마스터) 등장 → 고가 주문(150골드) + 스토리 전개 유도.
#### 업그레이드 구매 시나리오 (1~15일차) 1~5일: 캐릭터 수분보존 Lv1 → 6~8일: 가게 창고 Lv1 → 9~11일: 직원 조리보조 Lv1 → 12~15일: 김치 숙련도 Lv1 → 이후 가게 좌석 Lv1. (수입: 일평균 85골드, 지출: 75골드, 비율 1.13배 — 레벨10=195, 레벨50=1210 근접)

## 4. 시스템

### 시스템 (갱신본) **업그레이드 비용 곡선** (cost(n) = base × rⁿ)
- **가게**: base=15, r=1.32 → Lv1=15, Lv5=40, Lv10=200, Lv30=600, Lv50=1200 - **직원**: base=12, r=1.35 → Lv1=12, Lv5=35, Lv10=180, Lv30=580, Lv50=1180 - **캐릭터**: base=15, r=1.38 → Lv1=15, Lv5=45, Lv10=160, Lv30=540, Lv50=1100 - **김치**: base=12, r=1.40 → Lv1=12, Lv5=36, Lv10=140, Lv30=500, Lv50=1050 > *수입-지출 비율 1.1~1.3배 유지, 뽑기 500골드/일 한계 내 설계.* **업그레이드 효과 가안**
- 가게: 좌석 +1/레벨, 제작속도 +3%/레벨 (Lv30+ → +2%/레벨)
- 직원: 조리속도 +4%/레벨, 만족도 +2%/레벨 (Lv30+ → +1.5%/레벨)
- 캐릭터: MaxHP +6%/레벨, 수분보존 +2%/레벨, 인벤토리 +1슬롯/레벨 (Lv30+ → +1.5%/레벨)
- 김치: 발효속도 +5%/레벨, 옹기용량 +3%/레벨, 레시피 연구 +1/레벨 (Lv30+ → +2%/레벨) > *질적 진화: 초기 투자 몰입 강화 + 중후반 파워 크리프 방지로 지속적 성장감 제공.*

## 5. UI/UX

### UI/UX (최종본)
#### 화면 목록과 1순위 정보
1. **탑 선택 씬** — 탑 종류 및 층 선택 버튼 (가장 큰 버튼: “탐험 시작”)
2. **식재료의 탑** — 체력/수분(잔여량)/층 수/시계 UI (상단 고정, 클릭 가능 아이템 칸)
3. **주막(장사 준비)** — [장사 시작] 버튼 (중앙 하단, 크고 붉은색), 수분(잔여량) 표시 (바 아래), **시장 진입 버튼** (오른쪽 상단, 작고 흰색 테두리, “시장”)
4. **주막(장사 중)** — 손님 주문 팝업 (상단 중앙), 발효 진행 바 (오른쪽, 소모량 시각화)
5. **시장 씬** — 매대 3개 (좌: 요리 재료, 중: 상위 재료 로테이션, 우: 레시피 뽑기), **복귀 버튼** (하단 중앙, 주막 문 아이콘), 골드 잔액 (상단 고정), **의뢰 게시판** (좌측 하단, 붉은 테두리, “보스 김치 의뢰”)
6. **정산 씬** — [다음 날로] 버튼 (하단 중앙, 금색 배경), 수분(잔여량) 및 발효 효율 표시, **이월 재료: [파 3, 특제 양념 1]** (하단 작은 텍스트, 회색), **전설 김치 보유: [1]** (하단 우측, 금색 텍스트, 퀘스트 아이템 표시), **화련의 국자: 금빛 빛남** (중앙 상단, 애니메이션)
#### 핵심 플로우 탑 선택 → 식재료의 탑 (AM6~PM12) → 주막(장사 준비) (PM12~PM6) → **시장 진입** (PM6~PM7) → **의뢰 수주** → **“보스 김치 의뢰: 특수 재료는 보스에서만 드랍됨” 팝업 강제 노출** → 탑 진입 → 중간 보스 처치 → 전설 김치 획득 → 주막 진입 → 납품 → 정산 → 탑 선택
#### 온보딩 5단계
1. **탑 선택** — “탐험 시작” 버튼으로 첫 층 진입
2. **식재료의 탑** — 수분(잔여량) 획득 → 주막 발효 속도에 직접 반영
3. **주막 준비** — 수분(잔여량) 확인 후 [장사 시작] 클릭
4. **시장 진입** — **의뢰 게시판** 클릭 → **강제 팝업 노출** → **상위 재료 매대 무시**
5. **정산** — 수분(잔여량) 저장량과 발효 효율을 기반으로 다음 날 전략 수립, **전설 김치 보유 상태** 확인, **국자 금빛 빛남** 시각적 보상 인지
#### 플랫폼별 조작 유의점
- **PC (마우스)** — 이동: WASD, 상호작용: 좌클릭, 시장 매대: 마우스 오버로 재료 설명 및 제한 표시, **의뢰 게시판: 마우스 오버 시 “보스 김치 의뢰” 대사 노출**
- **모바일 (터치)** — 조이스틱으로 이동, 터치로 상호작용, 시장 매대: 터치로 구매, **의뢰 게시판: 빨간 점 + 진동으로 알림, 터치 시 강제 팝업 노출**
- **모든 플랫폼** — 수분(잔여량): 투명 청색 바, 발효 진행 바: 불투명 주황색 바, **시장 진입 버튼: 흰색 테두리 + 1px 흐림 효과로 구분**, **의뢰 게시판: 빨간 테두리 + 깜빡임 (수주 가능 시)**, **납품 후 국자 금빛 애니메이션** (전체 화면 흐림 + 부드러운 빛 퍼짐)
#### 시장 레벨디자인·맵 배치 초안 ``` [주막 문] │ ▼ [요리 재료 매대] — 부침가루, 식용유, 파, 마늘 (골드 50~150) [상위 재료 매대] — 상급 젓갈, 특제 양념, 고추가루(희귀) (1일 1회, ⭐) [레시피 뽑기] — 50골드/회, 일반 90%/희귀 9%/비밀 1% (확률 표시, 천장 50회) [의뢰 게시판] — “보스 김치 의뢰” (붉은 테두리, 클릭 시 강제 팝업) │ ▼ [복귀 버튼] — 주막 문 아이콘, 클릭 시 PM6~PM7 시간 차감 ```
#### 보스 김치 의뢰 챕터 표 — 3절 정본 표를 따른다 (이 절의 가안 표는 폐기)

> *수치는 밸런스 시트 위임. 전설 김치는 판매·소멸 불가. 보스 드랍률은 100% 고정. 의뢰는 1회성, 완료 시 다음 챕터 개방.*

> *모든 보스 스탯·드랍률·유산균 농도는 밸런싱 수치 시트로 넘깁니다. 전설 김치는 레시피 뽑기 미등록, 판매 불가. 유산균 농도는 제작 시 수분 +5%~20%, 풍미 +10~30점 보너스 적용.*

## 9. 기술

### 기술 명세: 슬라임 김치 (최종본)
1. **아키텍처**: 씬 기반 FSM 유지. `MarketManager` 추가, 탑/주막/시장 전환은 상태 이벤트로 처리.
2. **데이터 흐름**: `MarketInventory` ScriptableObject로 1일 3종 로테이션 및 1회 구매 제한 정의. 재료 이월은 `DailyStorage`에 골드 기반 잔여량 저장.
3. **컴포넌트 설계**: `MarketVendor`는 뽑기 확률을 일반 40% / 희귀 35% / 전설 25%로 조정. 중복 레시피는 자동 해금.
4. **결합 방식**: 시장 사용 시간은 주막 영업 시간에서 1:1 차감. 수분 0 시 ‘긴급 재료 구매’ 옵션 활성화로 선택권 보장.
5. **성능**: 로테이션은 `System.Random` + Seed(매일 00:00 재시작). K-Games 규제 준수: 확률 UI 명시, 3단계 확인 팝업.
6. **밸런싱**: 모든 수치는 가안이며, 밸런스 시트에 전달됨.
