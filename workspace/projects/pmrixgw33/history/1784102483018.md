### 1-5. "테라리아 첫인상" 콘텐츠 폭 (MVP 확대 정의 — 오너 지시 반영)
MVP는 일수(30일)뿐 아니라 **다음 코어 콘텐츠가 돌아가야 "테라리아 같다"는 인상**이 난다:
1. **광물·타일 티어 3단계** — 흙·돌 / 철·구리 / 얼음강철(심층) — 깊이 내려갈수록 좋은 자원.
2. **제작 트리 (v7 — 4단+제련)** — 작업대(조합) → 화로(철·구리 제련) → 용광로(얼음강철 제련) → 얼음 모루(성형). 광석→주괴→장비의 제련 층 추가, 단열·꾸미기 아이템 해금.
3. **발톱 강화 (v7 — 곡괭이 폐지)** — 고양이답게 발톱으로 직접 긁어 캔다. 광물 주괴로 발톱을 강화(맨발톱→무쇠 발톱→얼음강철 발톱), T2부터 고유 능력 부여 — 진행감의 핵심.
4. **지하 탐험 깊이** — 지하 3레이어(상·중·심층), 아래로 갈수록 어둡고 위험하며 보상이 크다.
5. **적 다양성** — 한국 요괴 5종 전부 구현(방망이 도깨비·불가사리·야광귀·어둑시니·강철이), 밤마다 조합 변화.
6. **건설 자유도** — 타일 자유 배치로 자기만의 석빙고 설계.
7. **보스전(소환식, v5)** — 보스 4종(도깨비 대장·어미 불가사리·이무기·강철이)을 소환템으로 유저가 원할 때 도전. 보스 전용 확정 드랍 = 석빙고 냉각 설비·터렛의 유일 재료.
8. **재미 확장(v6)** — 냥잠(보금자리 낮잠 = 시간 가속·체온 회복), 백중날 밤(15일차 고위험·고수익 이벤트 밤), 까치 벗(호작도의 까치 — 드랍 자동 줍기), 요괴 도감(민화 카드·전승 출처 표기). 벽타기는 확장 문서(31~100일) 전용.
9. **장비·악세사리·보물 상자(v8)** — 투구·갑옷·신발 3부위×3티어(짚·무쇠·얼음강철 — 최상위만 세트 효과 '설한풍 한벌옷'), 악세사리 6종은 **지하 보물 상자 파밍 전용**(테라리아 문법·장착 2칸), 상자 20개 절차 배치. 차용 맵은 3-6.

## 2. 세계관 (스토리 없음 — 환경 연출 전달)

### 세계관 태양이 하루가 지날수록 부풀어 오르며, 백일 후 세계를 태울 ‘백일폭염’이 다가온다. 낮은 화염처럼 뜨겁고, 밤만이 서늘한 유일한 휴식기. 고양이 ‘서리발톱’은 발톱으로 얼음을 다루며, 무너진 석빙고를 재건해 생존한다. 모든 서사는 화면 연출로 전달된다 — 대사 없고, 텍스트 없고, 오직 모션과 빛, 온도, 그리고 어둠이 말한다.
### 핵심 갈등 냉기란, 밤의 유일한 자원이자, 요괴들이 훔치고, 어둑시니가 먹고, 강철이가 밟는 마지막 희망이다.
### 주요 캐릭터
- **서리발톱**: 발톱에서 서리가 피어나는 고양이. 말 없이, 모션으로만 ‘지키겠다’는 의지를 표현.
- **어둑시니**: 빛이 없는 곳에서만 부풀어 오르는 요괴. 등불이 꺼진 곳에서만 진화하며, 빛을 맞으면 피해 2배 — 어둠이 곧 힘이다.
- **강철이**: 태양을 몸으로 키우는 뱀룡. 걸을수록 땅은 마르고, 그 발자국이 백일폭염의 진짜 원인.
- **야광귀**: 밤에 서늘한 물건을 훔치는 얄미운 도둑. 훔친 냉기 블록을 머리에 얹고, 허공에 떠다닌다.
### 스토리 훅
1. **1일차 밤**: 시작과 동시에 무너진 석빙고 흔적과, 평소 2배 크기의 태양이 보인다 — “이 집을 지키지 않으면, 아무것도 남지 않는다”는 메시지가 화면 자체가 전한다.
2. **어둑시니의 개화**: 등불이 꺼진 순간, 어둠 속에서 그림자가 부풀어 오르며, 빛을 향해 달려오는 요괴의 몸이 반짝인다 — “어둠이 힘이다”는 시스템이 스토리가 된다.
3. **밤 전환 예고**: 하늘은 60초 전부터 자주 흐려지고, D카운터가 0.5초 간격으로 깜빡이며, “밤이 온다”는 리듬이 플레이어의 신경을 예민하게 만든다.
4. **밀폐 누출**: 벽의 균열은 1초 주기로 푸른 점멸을 일으키며, 플레이어는 0.3초 안에 “이곳이 뚫렸다”고 직관적으로 인지한다.

## 3. 게임플레이

### 3-1. 코어 루프 다이어그램 (1일 = 낮 15분 + 밤 9분 — 정본 1-3 순서 준수) ``` [낮 15분 | 폭염 — 지상 제한] 지하 하강 → 광물 채집(발톱으로 긁기 — v7) → 제련·제작·발톱 강화 → 더 깊은 레이어 개척 ↓ [밤 9분 | 시원함 — 지상 개방] 지상 자원 수집 → 석빙고 증축·수리 → 요괴 습격 방어(광원 차단 대응) → 전리품 수거 ↓ [성장 환류] 전리품·상위 광물 → 상위 도구/모듈 제작 → 다음 낮, 더 깊고 유리하게 ``` 발톱 마모율: 낮 채집 시 매 5% 감소, 100% 소모 시 강화 불가 → 강화 필수 재도전 유도
### 3-2. 핵심 메커니크
1. **지하 3레이어 — 자연 게이트**: 진입 제한은 발톱 티어와 광원만. 일차 제한 없음.
2. **제작 트리**: 작업대 → 화로 → 얼음 모루. 근처 서 있으면 낮밤 무관 제작 가능.
3. **전투 루프**: 할퀴기 모션으로 근접 호 판정 → 넉백 확보 → 드랍(요괴 눈물+시그니처) → 얼음 모루 환류. 발톱과 무기 동일 로직.
4. **요괴 5종**: 스폰 로직은 정본 공식 **min(8, 1+floor((Day-1)/4))** 고수. 어둑시니는 등불 반경 내 피해 2배. 밤 습격은 광원 차단 패턴 점진적 증가 → 시야 축소 유도.
5. **악세서리 슬롯**: 총 10칸(반지2+목걸이1+오프핸드+가방+랜턴+주머니4). **순수 스탯 악세서리는 3칸 대비 2칸**으로 한정.
6. **발톱 강화 보상**: 채집 속도 +10% + **어둠 시야 확장 5%** (최대 +25%) → 탐색과 방어의 질적 전환 유도.
### 3-3. 세션 설계
- **한 세션**: 낮 15분 + 밤 9분 (24분)
- **리듬**: 낮(채집→제작→강화) → 밤(수집→건설→방어→수거) → 반복
- **반복 유도**: 발톱 마모 + 시야 확장 필요성 → 재도전과 전략적 광원 배치 유도
### 3-4. 리스크 **리스크**: 광원 차단 패턴이 플레이어를 과도하게 압박할 수 있음 **대비책**: 밤 습격 초기(1~10일)는 광원 차단 최대 15%만 적용 → D11부터 점진적 증가, 플레이어가 대응 전략을 익힐 시간 확보

## 4. 시스템

### 4-2. 밤 전환 예고 시스템 (v14 — 검토 반영) **왜 존재하는가**: 밤 습격의 불확실성을 의도적 긴장으로 전환해 플레이어의 사전 대비 유도.
- **T-60초 예고**: 하늘 팔레트 냉각 + D-100 점멸(기존 LUT/HUD 재사용).
