### 1-2. 핵심 훅 — "뒤집힌 낮밤" × "석빙고" × "테라리아 손맛"
낮=폭염으로 지상 불가, 밤=시원해 유일한 활동 시간이지만 도깨비 습격. 테라리아의 타일 파괴·제작·건설 손맛을 그대로 가져오되, "낮밤이 뒤집힌 생존"이라는 한 줄 차별점을 얹는다.

### 1-3. 코어 루프 (1일 = 24분)
낮 15분(지하 광물 채집·제작·도구 강화·석빙고 정비) → 밤 9분(지상 자원·석빙고 증축·도깨비 방어) → 10일마다 더위 단계 +1 → 30일 MVP 데모 엔딩 / 정식 100일 백일폭염.

### 1-6. "테라리아 첫인상" 콘텐츠 폭 (MVP 확대 정의 — 오너 지시 반영)
MVP는 일수(30일)뿐 아니라 **다음 코어 콘텐츠가 돌아가야 "테라리아 같다"는 인상**이 난다:
1. **광물·타일 티어 3단계** — 흙·돌 / 철·구리 / 얼음강철(심층) — 깊이 내려갈수록 좋은 자원.
2. **제작 트리** — 작업대 → 화로 → 얼음 모루. 도구·차열벽·석빙고 모듈이 티어별로 해금.
3. **도구 업그레이드** — 곡괭이/설치도구 티어(채집 속도·범위 상승) — 진행감의 핵심.
4. **지하 탐험 깊이** — 지하 3레이어(상·중·심층), 아래로 갈수록 어둡고 위험하며 보상이 크다.
5. **적 다양성** — 도깨비 4종 전부 구현(방망이·불·정예·최종), 밤마다 조합 변화.
6. **건설 자유도** — 타일 자유 배치로 자기만의 석빙고 설계.

## 2. 세계관·스토리

### 배경
지상의 태양이 날마다 조금씩 거대해지고 있다. 예언은 명확하다 — **딱 100일 뒤, 세계를 완전히 태워버릴 "백일폭염"이 온다.** 낮의 지상은 이미 화염처럼 뜨거워 발을 디딜 수 없고, 밤만이 서늘하게 숨 쉴 수 있는 시간이다. 톤은 공포가 아니라 **공포 없는 청량함과 역동적인 오싹함** — 여름밤 납량특집의 서늘한 재미다.

### 주인공 — 서리발톱
시원한 곳이라면 어디든 찾아드는 고양이. 낮에는 그늘에서 헥헥거리다가, 밤이 되면 눈을 반짝이며 집을 짓는다. 백일폭염에서 살아남는 방법은 하나 — 옛 조상들이 여름 얼음을 지키던 **석빙고(石氷庫)**를 완벽한 밀폐형 기지로 완공하는 것. 발톱에 서리가 맺힐 만큼 차가운 얼음 블록을 다루는 솜씨 때문에 "서리발톱"이라 불린다.

### 주적 — 도깨비들
한국 전통 도깨비들이 밤마다 석빙고의 냉기를 노리고 몰려온다. 무섭다기보다 **얄밉다** — 불을 뿜어 얼음을 녹이고, 방망이로 벽을 쿵쿵 때리고, 애써 쌓은 타일을 부수고 도망간다. 폭염의 세상에서 시원함은 가장 귀한 보물이고, 도깨비들도 그것을 원한다.

### 스토리 훅
1. **1일차 밤** — 하늘의 태양이 두 배로 커진 날, 서리발톱은 무너진 옛 석빙고 터를 발견하고 대작전을 시작한다.
2. **10일차마다** — 태양이 한 단계 더 커지고(더위 단계 +1), 도깨비들의 습격도 거세진다.
3. **100일차** — 백일폭염 도래. 밀폐형 석빙고가 완공되어 있다면 서리발톱은 서늘한 어둠 속에서 여름을 이겨낸다.

## 3. 게임플레이

### 코어 루프 다이어그램 낮(화염 디버프·정비·체온 회복) → 밤(지하 탐색·광물 채집·제작·도깨비 방어) → 새벽 귀환 → 10일마다 더위 단계 +1 → 30일차 백일폭염 전 밀폐형 석빙고 완공
### 핵심 메커니크
1. **지하 3레이어 탐색** — 1층(흙/돌), 2층(얼음), 3층(심층얼음). 각 레이어는 5일마다 열리며, 도구 티어(곡괭이→강화곡괭이→마력곡괭이)로만 채집 가능.
2. **3티어 제작 트리** — 광물(흙→돌→얼음) → 도구(곡괭이→등불→차열벽) → 구조(벽면→방어망→완성모듈). 제작은 밤에만 가능, 레시피는 지하 레이어에서 획득.
3. **도깨비 4종 출현 로직** — 방망이(1~10일), 불(6~15일), 둘 동시(11~20일), 빠른 도깨비(21~30일, 15초 이내 돌진). 스폰 수는 min(8, 1+floor((Day-1)/5)).
### 세션 설계 1일 = 낮 15분 + 밤 9분 (총 24분). MVP는 30일 루프(12시간). 세션은 5일 단위로 구간(1~5, 6~10, 11~15, 16~20, 21~30)으로 구성. 각 구간 끝에 ‘등불 설치’ 퀘스트로 리셋, 5일마다 ‘얼음 10개 수집’ 이벤트로 스폰 위치 확장.
### 리스크 1개 **리스크**: 빠른 도깨비의 급격한 돌진으로 플레이어 반응 시간 부족 → **대비책**: 15초 돌진 전 5초 경고 흔들림 + 등불 반경 30% 확장으로 회피 전략 유도.

## 4. 시스템

### 시스템: 성장 축 목록
1. **체온 축** (주기: 1분) — *왜 존재하는가?* 플레이어가 석빙고 보존을 실감하게 하기 위해.
2. **밀폐도 축** (주기: 밤마다) — *왜 존재하는가?* 밤 활동의 지속적 보상으로 공간 전략을 질적으로 진화시키기 위해.
3. **타일 수집 축** (주기: 밤마다) — *왜 존재하는가?* 파괴와 재배치의 만족감을 반복적으로 유도하기 위해.
4. **도깨비 방어 축** (주기: 밤 습격마다) — *왜 존재하는가?* 공격-방어 루프로 밤의 긴장감을 질적으로 진화시키기 위해.
5. **광물 티어 수집 축** (주기: 낮/밤 채집 시) — *왜 존재하는가?* 테라리아식 탐색 보상으로 지하 레이어 탐험을 동기부여하기 위해.
6. **도구 업그레이드 축** (주기: 제작 완료 시) — *왜 존재하는가?* 채집/건설 효율의 질적 진화로 플레이어의 전략적 선택을 확장하기 위해.
### 재화 표

| 재화 | 획득처 | 소비처 | 병목 |
|---|---|---|---|
| 얼음 조각 | 밤 타일 파괴 | 석빙고 증축, 체온 보존 | 타일 파괴 속도 |
| 철근 | 낮 폐허 파괴 | 구조 강화, 밀폐도 증가 | 낮 활동 시간 부족 |
| 도깨비 눈물 | 습격 성공 시 +1, 밤 활동 30분당 +0.2 | 특수 장치 제작 | 활동 지속 유도 필요 |
| 광물 티어1~3 | 지하 레이어 채집 | 도구 제작·업그레이드 | 도구 티어1 진입 조건 |
### 콘텐츠 진행 구조
- **스테이지**: 10일 단위 (총 3스테이지, 30일)
- **챕터**: 밤 습격 유형 변화 (도깨비 4종: 방망이, 불, 둘 동시, 빠른) + 지하 레이어 해금 (5/10/15일)
- **시즌**: 백일폭염 전 마지막 10일 — “밀폐도 100% + 도구 티어3 완성” 도전 모드
### 시스템 의존 다이어그램 체온 ↓ → 밀폐도 ↑ 필요 지하 레이어1 진입: 5일 경과 + 광물 티어1 → 도구 티어1 해금 도구 티어 ↑ → 채집 효율 ↑ → 타일 수집 속도 ↑ → 밀폐도 ↑ 도깨비 눈물 축적 → 특수 장치 제작 → 밀폐도 +1% → 다음 챕터 열림

## 5. UI/UX

1. **홈 화면**: D-100 카운트다운 (중앙 대형 숫자), 서리발톱 애니메이션 (오른쪽 하단) — 기존 유지  
2. **게임 화면**: 체온 바 (상단 왼쪽), 밀폐도 게이지 (상단 오른쪽), 타일 배치 툴 팔레트 (하단 고정), 밤 전용 모드 아이콘 (청색 점멸) — 기존 유지  
3. **인벤토리 화면**: 3×4 그리드 (12슬롯), 상단 고정 탭: "채집" / "제작" / "도구" — 좌우 스와이프, 1회 터치로 열림  
4. **제작 트리 화면**: 3단계 구조 (정본 정의) — **1단계: 광물 채집** (지표/중층/심층 광물) → **2단계: 도구 제작** (도끼/삽/망치) → **3단계: 구조 건설** (얼음 블록/차열벽/석빙고 모듈 5종). 비활성 노드 흐림, 활성화 시 연결선 투명 표시.  
5. **도구 강화 화면**: 도구 3종, 각 3단계 강화, 필요 재료 명시, 부족 시 빨간 ❌ 아이콘 — 자원 관리 피드백 유지  
6. **채집 탭 하단**: 지하 레이어 힌트 — 3단계 아이콘 (지표 / 중층 / 심층), 터치 시 채집 가능 광물 리스트 확장  
7. **제작·건설 패널**: 밤 활성, 인벤토리 하단 팝업으로 통합 — 구조 티어 노드와 동일한 인터페이스  
8. **플랫폼별 조작**:  
- **모바일**: 탭 스와이프, 트리 노드 터치 1회, 지하 레이어 터치 확장, 강화 재료 부족 시 ❌ 강조

## 9. 기술

### 기술: 유니티 9일 구현 명세 (최종본)
- **타일맵**: `Tilemap` + `TilemapRenderer`로 지상/지하 3레이어 구조, `ScriptableObject`로 16×16px 도트 타일셋(지상: 얼음/석빙고, 지하: 석영/철광석/냉광석) 관리.
- **낮밤 로직**: `TimeOfDayManager`로 **낮 900초/밤 540초** 사이클, `DayNightCycle`로 화염 디버프(1.5HP/sec) + 아지랑이 Shader 제어.
- **지하 생성**: `PerlinNoise` + `Tilemap.SetTile`로 지하 3레이어 생성, `CullingGroup`으로 렌더링 최적화.
- **제작 트리**: `ScriptableObject`로 12종 아이템 트리 정의, `CraftingStation`으로 재료 소모 + 결과 생성.
- **도구 티어**: 곡괭이(1티어) → 강화곡괭이(2티어) → 마력곡괭이(3티어), 채집/파괴 효율 각 +20%, `UpgradeSystem`으로 인벤토리 강화 UI 연동.
- **도깨비 AI**: 방망이/수직슬라이스/불/바람 도깨비 4종, `FSM`으로 Spawn→Approach→AttackWall→Flee, **밤에만 스폰**, **새벽 3분 전 자동 경고 + 이동 속도 50% 감소**로 도주.
- **우선순위**:
1) 타일맵+지하 생성(D1~2),
2) 낮밤+체온(D3),
3) 제작 트리+도구 티어(D4~5),
4) 도깨비 AI+밀폐도 연동(D6~7),
5) HUD+인벤토리(D8),
6) 테스트/패치(D9).
- **리스크**: 지하+제작 트리 동시 로딩 → `Addressables`로 에셋 로드 분산, FPS 60 유지.
- **권장 스택**: Unity 2023.2 LTS, URP, Tilemap Extras, Cinemachine, Addressables.
