### 1-2. 핵심 훅 — "뒤집힌 낮밤" × "석빙고"

테라리아류의 상식(낮=안전, 밤=위험)을 뒤집는다. **낮은 거대해진 태양의 화염 데미지 때문에 지상에 오래 못 있고, 밤은 시원해서 유일한 활동 시간**이지만 도깨비들이 석빙고의 냉기를 노리고 몰려온다. 여름의 더위를 잊게 하는 서늘한 감각(납량→냥량)을 한국 전통 건축 "석빙고(石氷庫)"로 구현 — 고양이가 시원한 곳을 찾아드는 습성과 테마가 하나로 묶인다.

### 1-3. 코어 루프 (1일 사이클)

낮(화염 디버프): 지하·석빙고 안에서 제작·정비 → 밤(냉량): 타일 파괴로 자원 채집, 석빙고 증축, 도깨비 돌진 방어 → 새벽: 귀환 → 10일마다 더위 단계 상승으로 낮은 더 가혹해지고 밤 요괴는 더 강해진다 → 100일째 백일폭염 도래 전 밀폐형 석빙고 완공 시 승리.

### 1-5. 해커톤 스코프 가드 (전 부서 준수)

- **MVP = 20일차까지의 루프**가 1차 목표. 21~100일 콘텐츠는 확장 설계(문서만)로 분리한다.
- 모든 설계는 "9일 안에 구현 가능한가"를 1차 기준으로 판정한다.
- 맵: 지상 1레이어 + 지하 1~2레이어의 단일 월드. 바이옴 다양화 금지.

## 2. 세계관·스토리

### 배경
지상의 태양이 날마다 조금씩 거대해지고 있다. 예언은 명확하다 — **딱 100일 뒤, 세계를 완전히 태워버릴 "백일폭염"이 온다.** 낮의 지상은 이미 화염처럼 뜨거워 발을 디딜 수 없고, 밤만이 서늘하게 숨 쉴 수 있는 시간이다. 톤은 공포가 아니라 **공포 없는 청량함과 역동적인 오싹함** — 여름밤 납량특집의 서늘한 재미다.

### 주인공 — 서리발톱
시원한 곳이라면 어디든 찾아드는 고양이. 낮에는 그늘에서 헥헥거리다가, 밤이 되면 눈을 반짝이며 집을 짓는다. 백일폭염에서 살아남는 방법은 하나 — 옛 조상들이 여름 얼음을 지키던 **석빙고(石氷庫)**를 완벽한 밀폐형 기지로 완공하는 것. 발톱에 서리가 맺힐 만큼 차가운 얼음 블록을 다루는 솜씨 때문에 "서리발톱"이라 불린다.

### 주적 — 도깨비들
한국 전통 도깨비들이 밤마다 석빙고의 냉기를 노리고 몰려온다. 무섭다기보다 **얄밉다** — 불을 뿜어 얼음을 녹이고, 방망이로 벽을 쿵쿵 때리고, 애써 쌓은 타일을 부수고 도망간다. 폭염의 세상에서 시원함은 가장 귀한 보물이고, 도깨비들도 그것을 원한다.

### 스토리 훅
1. **1일차 밤** — 하늘의 태양이 두 배로 커진 날, 서리발톱은 무너진 옛 석빙고 터를 발견하고 대작전을 시작한다.
2. **10일차마다** — 태양이 한 단계 더 커지고(더위 단계 +1), 도깨비들의 습격도 거세진다.
3. **100일차** — 백일폭염 도래. 밀폐형 석빙고가 완공되어 있다면 서리발톱은 서늘한 어둠 속에서 여름을 이겨낸다.

## 3. 게임플레이

### 코어 루프 다이어그램
낮(화염 디버프·정비) → 밤(타일 채집·석빙고 증축·도깨비 방어) → 새벽 귀환 → 10일마다 더위 단계 +1 → 100일차 백일폭염 전 밀폐형 석빙고 완공.

### 핵심 메커니크
1. **낮/밤 환경 디버프** — 낮 지상은 화염 데미지(틱당 피해) + 아지랑이 화면 연출. 그늘·지하·석빙고 내부는 안전. 밤은 디버프 없음.
2. **테라리아식 타일 파괴·배치** — 곡괭이질로 흙·돌·얼음 타일을 캐고, 석빙고 벽면·차열벽으로 배치한다. 얼음 블록은 밤 지하에서만 채집 가능한 핵심 자원.
3. **도깨비 스폰·돌진 AI** — 밤 시간대 기지 주변에 스폰, 석빙고를 향해 돌진. 불도깨비는 얼음을 녹이고, 방망이 도깨비는 벽을 부순다. 10일마다 스폰 수·강도 상승. [가안] 등불로 유도·회피 가능.
4. **체온 게이지 [가안]** — 낮 노출 시 상승, 그늘·지하·밤·얼음 근처에서 하강. 기본 사이클은 순증 0으로 설계하고, 더위 단계가 오를수록 낮 상승 속도만 가팔라진다 (수치는 6장 밸런스에서 정본화).

### 세션 설계
1일 = 낮 3분 + 밤 3분 [가안, 팀 예시]. **MVP는 20일차까지의 루프** (약 2시간 분량) — 심사 시연은 시작 세이브 3종(1·8·15일차)으로 압축 체험.

### 리스크·대비책
- **리스크**: 후반 도깨비 수 증가로 밤 난이도 폭주 → **대비책**: 스폰 수는 상한(예: 8마리 [가안])을 두고, 등불·방벽 등 방어 수단의 효율을 함께 올려 체감 난이도를 계단식으로 유지.
- **리스크**: 9일 내 타일맵+AI+낮밤 로직 동시 구현 부담 → **대비책**: MVP 20일 루프 우선, 요괴 1종(방망이 도깨비)부터 수직 슬라이스.

## 4. 시스템

### 시스템: 성장 축 목록
1. **체온 축** (주기: 1분) — *왜 존재하는가?* 플레이어가 석빙고 보존을 실감하게 하기 위해.
2. **밀폐도 축** (주기: 밤마다) — *왜 존재하는가?* 밤 활동의 지속적 보상으로 공간 전략을 질적으로 진화시키기 위해.
3. **타일 수집 축** (주기: 밤마다) — *왜 존재하는가?* 파괴와 재배치의 만족감을 반복적으로 유도하기 위해.
4. **도깨비 방어 축** (주기: 밤 습격마다) — *왜 존재하는가?* 공격-방어 루프로 밤의 긴장감을 질적으로 진화시키기 위해.
### 재화 표

| 재화 | 획득처 | 소비처 | 병목 |
|---|---|---|---|
| 얼음 조각 | 밤 타일 파괴 | 석빙고 증축, 체온 보존 | 타일 파괴 속도 |
| 철근 | 낮 폐허 파괴 | 구조 강화, 밀폐도 증가 | 낮 활동 시간 부족 |
| 도깨비 눈물 | 습격 성공(80%) + 밤 활동 30분 이상(20%) | 특수 장치 제작 | 활동 지속 유도 필요 |
### 콘텐츠 진행 구조
- **스테이지**: 10일 단위 (총 10스테이지)
- **챕터**: 밤 습격 유형 변화 (도깨비 4종 등장: 바람, 물, 땅, 불)
- **시즌**: 백일폭염 전 마지막 10일 — “밀폐도 100%” 도전 모드
### 시스템 의존 다이어그램 체온 ↓ → 밀폐도 ↑ 필요 밀폐도 ↑ → 타일 수집 효율 ↑ 타일 수집 ↑ → 도깨비 방어 장치 제작 가능 도깨비 습격 성공 + 밤 활동 30분 → 도깨비 눈물 획득 → 특수 장치 해금 → 밀폐도 +1% → 다음 챕터 열림

## 5. UI/UX

### 화면 목록과 1순위 정보
1. **홈 화면**: D-100 카운트다운 (중앙 대형 숫자), 서리발톱 애니메이션 (오른쪽 하단)
2. **게임 화면**: 체온 바 (상단 왼쪽), 밀폐도 게이지 (상단 오른쪽), 타일 배치 툴 팔레트 (하단 고정), **밤 전용 모드: 활성** 아이콘 (체온 바 오른쪽, 청색 점멸)
3. **밤 전투 화면**: 도깨비 경고 테두리 (화면 외곽 진동), 적 위치 힌트 (투명한 얼음 발자국)
4. **성장 화면**: 석빙고 확장 이력 (오른쪽 슬라이딩 타임라인), 자원 수확량 누적 그래프
5. **상점 화면**: 얼음 블록·서리 흡수기·방어 타일 (3열 그리드), 가격은 “= 1.2분 밤” 형식으로 표시 (예: 얼음 블록 5 = 6분 밤)
### 핵심 플로우 홈 → 게임 화면 (낮) → 밤 전투 화면 → 성장 화면 → 상점 → 게임 화면 (다음 낮)
### 온보딩 5단계
1. **D-100 카운트다운을 읽는 법** — 화면 상단 중앙 고정, 초반 3초 동안 확대 강조
2. **체온 바가 떨어지면 사망** — 체온 20% 이하에서 화면 흐림 + 경고음 테스트
3. **밤 전용 모드에서만 타일 배치·파괴 가능** — 첫 밤, 자동으로 툴 팔레트 활성화 + 터치 가이드 + 아이콘 점멸 강조
4. **도깨비는 얼음 발자국으로 예고** — 첫 스폰 시, 발자국 3초 동안 반짝이며 노출
5. **밀폐도가 100%가 되면 승리** — 20일차 기준, 마지막 타일 배치 후 화면 전체 얼음 빛 반사
### 플랫폼별 조작 유의점
- **모바일**: 터치로 타일 배치, 드래그로 카메라 이동, 더블탭으로 빠른 재배치
- **PC**: 마우스 왼쪽 클릭으로 배치, 오른쪽 클릭으로 파괴, 스페이스바로 빠른 전환 (낮/밤)
- **콘솔**: 좌스틱으로 이동, A/X로 배치, B/O로 파괴, D패드로 툴 전환 — 모든 조작은 1회 입력으로 완료

## 6. 밸런스

### 밸런스 설계: 《100일의 냥빙고》20일 MVP 기준 **1. 기준 수치 표 (레벨 1/10/20)**

| 스탯 | 레벨 1 | 레벨 10 | 레벨 20 |
|---|---|---|---|
| 체온 | 100 | 130 | 160 |
| 밀폐도 | 0% | 45% | 80% |
| 방어력 | 5 | 18 | 35 |
| 도깨비 저항 | 0% | 30% | 60% |

**2. 성장 곡선 공식**
- 체온 = 100 + 3 × Lv (선형)
- 밀폐도 = 0.5 × Lv² (최대 85%)
- 방어력 = 5 × (1 + 0.15 × Lv)
- 도깨비 저항 = min(60%, 3 × Lv)
**3. 난이도 곡선 (6분 사이클 기준)**
- 레벨 1~5: 밤 1~2마리 도깨비 (기본돌진, 데미지 8)
- 레벨 6~12: 밤 3마리 (1마리 폭풍돌진, 데미지 15)
- 레벨 13~20: 밤 4마리 (2마리 폭풍돌진, 1마리 흡수, 데미지 20) → **밀폐도 80% 도달 시 도깨비 데미지 30% 감소**
**4. 붕괴 시나리오** **경로**: 플레이어가 밤에 타일 채집만 하며 밀폐도를 무시 → 레벨 15에서 체온 120 이하 → 낮 화염 데미지 25/틱 → 3일 내 사망. **방지책**: 밀폐도 30% 미만 시, 낮 화염 데미지 +50% (강제 건설 유도). --- *모든 수치는 9일 개발 기간 내 유니티 구현 가능. 체온 선형 성장, 도깨비 데미지 감소로 AI 복잡도 절감.*

## 7. 수익모델

### 추천 BM: **심사 어필 포인트 기반 ‘무과금 완전체’ 전략** 해커톤 특례로 과금 시스템을 배제하고, **“100일 동안 모든 플레이어가 공평하게 완성하는 석빙고”** 라는 주제를 **심사위원의 감동 포인트**로 전환.
### 차선: **광고 기반 ‘清凉(청량) 브랜드 파트너십’** 낮의 체온 회복 완료 후 3초 대기 시, 사용자가 수동으로 닫을 수 있는 가벼운 냉면/빙수 브랜드 배너 노출.
### 과금 상품 구성표 *없음 — 과금 없음.* → 대신 **“완성 석빙고 기념 디지털 스티커 팩”** 은 100일차 완성 후, 플레이어가 직접 ‘공유하기’ 버튼을 눌러야만 활성화.
### 첫 결제 유도 설계 *없음.* → 대신 **“100일차 완성 시, 시스템이 자동으로 당신의 석빙고를 ‘국가문화유산 디지털 아카이브’에 등록”** 하는 감동적 마무리.
### 윤리·규제 리스크 **확률형 아이템 없음 → 고지 텍스트 불필요.** **현금 가챠 절대 불도입 → K-Games 규정·플랫폼 정책 완전 준수.** → **“무과금 완성형”이 오히려 심사 기준 ‘혁신적 윤리 디자인’으로 어필 가능.**

## 8. 아트

### 아트 디렉션: 《100일의 냥빙고: 서리발톱 대작전》
1. **스타일 정의**: 16비트 도트 아트 — 테라리아의 타일 기반 건설 + 한국 석빙고 문양의 정교한 반복 패턴. 레퍼런스: *Stardew Valley*의 색감 조절 + *Hollow Knight*의 음영 밀도.
2. **컬러 팔레트**:
- 주조색: `#E0F7FF` (얼음청)
- 보조색: `#B0D0E0` (차가운 회색)
- 포인트색: `#FF6B00` (위험 경고 주황)
3. **분위기 키워드**: 청량한 위기, 역동적 오싹함, 정밀한 취약성, 전통적 경계, 서리의 침묵
4. **프로덕션 난이도 메모**:
- 타일셋: 한국 석빙고 벽 4종 + 얼음 블록 2종 — 외부 물 흐름 제거, 내부 결빙만 유지.
- 도깨비 4종: 동일 구조 + 색상 변형 — 발광 강도로 밀폐도 경고 연동.
- 서리발톱 귀: 도깨비 근접 시 점진적 주황 발광 — 체온 저하 & 밀폐도 감소와 연동된 시각적 경고.
- 태양 광선: 수평 이동 애니 — 1개 오브젝트로 전체 화면 렌더링.
- **리스크**: 투명도 계층은 Sprite Renderer + Sorting Layer로 관리 가능.

## 9. 기술

### 기술: 유니티 9일 구현 명세
- **타일맵**: `Tilemap` + `TilemapRenderer`로 2D 석빙고 구조, `ScriptableObject`로 얼음/석빙고 타일셋(32x32 도트) 관리.
- **낮밤 로직**: `TimeOfDayManager`로 6분 사이클, `DayNightCycle` ScriptableObject로 화염 디버프(낮: 1.5HP/sec, 그늘:
0) 및 아지랑이 Shader 제어.
- **도깨비 AI**: `Grid-Based Pathfinding`(A* on Tilemap) + `Behavior Tree`로 타일 기반 이동, 밀폐도 <30% 시 자동 경로 차단(환경적 장벽). 4종(불/얼음/바람/그림자)은 밤 30초 간격 스폰, 15m 내 돌진(속도 2.5u/s).
- **우선순위**:
1) 타일맵 + 낮밤 로직 (D1~3),
2) 서리발톱 체온 (D4),
3) 도깨비 AI + 장벽 로직 (D5~6),
4) 밀폐도 연동 타일 파괴 (D7),
5) HUD + 카운트다운 (D8),
6) 테스트/패치 (D9).
- **리스크**: 타일 파괴 + AI 동시 렌더링 → `CullingGroup` + `JobSystem`으로 경로 계산 병렬화, FPS 60 유지.
- **권장 스택**: Unity 2023.2 LTS, URP, Tilemap Extras, Cinemachine, Addressables.
