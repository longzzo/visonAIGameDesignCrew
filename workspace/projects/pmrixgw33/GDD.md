### 1-2. 핵심 훅 — "뒤집힌 낮밤" × "석빙고" × "테라리아 손맛"

### 1-6. "테라리아 첫인상" 콘텐츠 폭 (MVP 확대 정의 — 오너 지시 반영)
MVP는 일수(30일)뿐 아니라 **다음 코어 콘텐츠가 돌아가야 "테라리아 같다"는 인상**이 난다:
1. **광물·타일 티어 3단계** — 흙·돌 / 철·구리 / 얼음강철(심층) — 깊이 내려갈수록 좋은 자원.
2. **제작 트리** — 작업대 → 화로 → 얼음 모루. 도구·차열벽·석빙고 모듈이 티어별로 해금.
3. **도구 업그레이드** — 곡괭이/설치도구 티어(채집 속도·범위 상승) — 진행감의 핵심.
4. **지하 탐험 깊이** — 지하 3레이어(상·중·심층), 아래로 갈수록 어둡고 위험하며 보상이 크다.
5. **적 다양성** — 한국 요괴 5종 전부 구현(방망이 도깨비·불가사리·야광귀·어둑시니·강철이), 밤마다 조합 변화.
6. **건설 자유도** — 타일 자유 배치로 자기만의 석빙고 설계.

## 2. 세계관 (스토리 없음 — 환경 연출 전달)

**원칙: 컷신·대사·NPC 대화·텍스트 스토리텔링 없음. 모든 서사는 화면 연출(배경·스폰·오브젝트 변화)로만 전달한다 — 테라리아 방식.**

### 배경 — 백일폭염
태양이 날마다 커져 딱 100일 뒤 세계를 태워버리는 "백일폭염"이 온다. 낮의 지상은 화염처럼 뜨겁고, 밤만이 서늘하게 숨 쉴 수 있는 시간이다. 톤은 정본 그대로 — 공포가 아닌 **공포 없는 청량함과 역동적인 오싹함**, 여름밤 납량특집의 서늘한 재미.
- **인게임 표현**: 배경 태양 스프라이트가 더위 단계(10일)마다 실제로 커지고 하늘 팔레트가 청→주황→적으로 물든다. 낮 지상의 아지랑이 셰이더와 화염 디버프 이펙트가 "말 없이" 위험을 전달.

### 주인공 — 서리발톱
발톱에 서리가 맺힐 만큼 얼음 블록을 잘 다루는 고양이. 옛 조상들의 석빙고(石氷庫) 터를 밀폐형 기지로 완공하는 것이 유일한 생존법이다.
- **인게임 표현**: 대사 없음. 낮에는 헥헥거리는 idle 모션과 체온 바 상승, 밤에는 눈이 반짝이는 스프라이트로 전환 — 캐릭터 성격은 전부 모션으로만 전달.

### 주적 — 요괴들 (폭염의 세상에서 냉기를 탐하다 — v4 오너 지시로 5종 확장)
백일폭염이 다가올수록 세상에서 가장 귀한 보물은 금은도 쌀도 아닌 '냉기'가 되었다. 그래서 밤마다 요괴들이 석빙고로 몰려든다 — 방망이 도깨비는 씨름 한판 걸듯 벽을 두들기고, 불가사리는 무쇠 골조를 간식처럼 갉아먹고, 야광귀는 서늘한 밤 틈에 남의 살림을 슬쩍하고, 어둑시니는 등불 꺼진 심층 어둠에서 슬금슬금 몸집을 불린다. 이들은 무서운 침략자가 아니라 시원한 것 앞에서 염치를 잊은 얄미운 이웃들이다. 그리고 이 소동의 꼭대기에 강철이가 있다 — 지나간 자리마다 가을걷이가 봄 보릿고개가 된다는 그 뱀룡이 하늘을 배배 꼬며 돌수록 태양은 나날이 부풀어 오르니, 백일폭염이란 곧 강철이의 산책길인 셈이다. 서리발톱의 석빙고는 요괴들에게 마지막 남은 얼음 곳간이자, 강철이에게는 제 폭염에 굴복하지 않는 단 하나의 눈엣가시다. (전승 근거: 구비 도깨비 씨름담 · 《송남잡지》 불가사리 · 《동국세시기》 야광귀 · 어둑시니 구전 · 《성호사설》 강철)
- **인게임 표현**: 철을 갉고(불가사리), 훔치고(야광귀), 부풀고(어둑시니), 마른 궤적을 남기는(강철이) 각 요괴의 모션이 곧 서사다 — 컷신·대사 없음. 새벽 50% 감속 퇴각(9장)은 전 종 공통 '얄미운 익살' 연출.

### 연출 비트 (구 스토리 훅 — 전부 화면 연출로 대체)
1. **1일차 밤 (오프닝)** — 컷신 없음. 시작 지점 옆에 무너진 석빙고 폐타일 더미와 평소 2배 크기 태양을 배치. 플레이어가 첫 화면을 본 순간 "짓고 버텨야 한다"를 스스로 이해한다.
2. **10일차마다 (에스컬레이션)** — 태양 스프라이트 확대 + 하늘 팔레트 변경 + 요괴 스폰 수·조합 강화(6장 곡선 준수). 숫자가 아니라 화면과 습격 압박으로 위기를 체감시킨다.
3. **30일차 데모 엔딩 / 정식 100일차** — 백일폭염 도래를 화면 전체 백열 화이트아웃으로 표현 → 밀폐도 100%이면 석빙고 내부의 서늘한 청색 화면 + 잠든 서리발톱 스프라이트로 전환. 텍스트는 "D-0" 한 줄뿐. 보스 강철이는 30일차엔 옅은 주황 '풋강철이'(축소 스케일), 100일차엔 태양과 같은 적색·백열 완전체 — 스프라이트 1벌 + LUT 스왑(8장). (기존 배경·스프라이트·HUD 재활용 — 전용 컷신 시스템 불필요)

### 조선 민화풍 텍스처
석빙고는 조선 시대에 겨울 얼음을 여름까지 보관하던 실존 석조 얼음 창고다 — 경주 석빙고처럼 남아 있는 실물이 이 게임의 "밀폐형 기지"에 역사적 실감을 준다. 도깨비 또한 민화 속에서 사람을 골탕 먹이되 어딘가 어수룩하게 당하는 익살꾼으로 그려져 왔다. 이 두 전통이 8장 아트의 도트·석빙고 문양 타일셋과 맞물려, "납량 = 공포"가 아닌 "납량 = 여름밤의 서늘한 익살"이라는 정본 톤의 근거가 된다.

### 스코프 가드
신규 고유명사(요괴 5종·설치물 3종)는 4-1 정본 명칭 표에 등록(오너 지시 2026-07-14). 모든 연출은 기존 오브젝트(배경 스프라이트·타일·스폰 로직·HUD) 재활용으로 구현하며, 전용 컷신 시스템 없이 5명·9일 내 신규 시스템 최소화(등불·체·해태는 공통 설치물 로직 재사용)를 전제로 한다.

## 3. 게임플레이

### 3-1. 코어 루프 다이어그램 (1일 = 낮 15분 + 밤 9분 — 정본 1-3 순서 준수)
```
[낮 15분 | 폭염 — 지상 제한]
  지하 하강 → 광물 채집(곡괭이) → 제작대에서 제작·도구 강화 → 더 깊은 레이어 개척
      ↓
[밤 9분 | 시원함 — 지상 개방]
  지상 자원 수집 → 석빙고 증축·수리 → 요괴 습격 방어 → 전리품(요괴 눈물 등) 수거
      ↓
[성장 환류] 전리품·상위 광물 → 상위 도구/모듈 제작 → 다음 낮, 더 깊고 유리하게
```
10일마다 더위 단계 +1(정본) → 낮은 더 가혹해지고 밤 습격은 거세져 루프 압력이 우상향한다.

### 3-2. 핵심 메커니크
1. **지하 3레이어 — 자연 게이트 (시간 게이트 없음)**: 상층(흙·돌)·중층(철·구리)·심층(얼음강철)은 **처음부터 물리적으로 존재**하며 1일차에도 파고 내려갈 수 있다. 진입을 막는 것은 일수가 아니라 ① **곡괭이 티어** — 심층 얼음강철은 상위 곡괭이로만 채굴 가능(티어 3단계, 정본 1-6) ② **환경 위험** — 깊을수록 어둡고(광원 필요) 심층에는 어둑시니가 상주(빛 없으면 거대화 — 등불 필수). "일찍 무리해서 내려가기"는 금지가 아니라 리스크 높은 플레이어 선택이다.
2. **제작 트리 — 작업대 → 화로 → 얼음 모루**: 해당 제작대 **근처에 서 있으면 낮밤 무관 언제든 제작 가능**(테라리아식). 상위 제작대가 상위 레시피(도구·차열벽·석빙고 모듈)를 해금하며, 제작대 자체를 어디에 놓을지가 거점 설계의 일부다.
3. **전투 루프 (테라리아식 근접)**: 곡괭이/무기 휘두르기 = **전방 근접 호(arc) 판정** → 명중 시 **넉백**으로 거리 확보 → 처치 시 **드랍(요괴 눈물 + 종별 시그니처 재료)** → 얼음 모루의 특수 레시피(차열벽 강화·석빙고 모듈 부품)로 환류. 곡괭이와 무기는 동일 스윙 로직을 공유한다. ※ 데미지·넉백 거리·드랍률 등 수치는 6장 밸런스 확정 사항.
4. **요괴 5종 출현 로직 (정본 명칭 4-1)**: **방망이 도깨비**(1일~ — 벽 타격 기본형) / **불가사리**(6일~ — 철 구조물 포식 + 화염 숨결 얼음 용해, 무쇠 차열벽 면역) / **야광귀**(11일~ — 파괴 대신 절도 후 도주, 체(篩) 앞에선 구멍 세느라 밤새 정지) / **어둑시니**(16일~ — 심층 상주 + 밤 지상 합류, 등불 반경 내 받는 피해 2배) / **강철이**(30일차 밤 고정 1 — 백일폭염의 원흉, 정식판 100일차 본체). 밤 스폰 수는 정본 공식 **min(8, 1+floor((Day-1)/4))** 만 사용. 수치는 6-7 전투표.

### 3-3. 세션 설계 (24분 × 30일 MVP)
- 진행 체감은 시간제 퀘스트·수집 이벤트가 아닌 **유기적 마일스톤** 3축으로 만든다:
  ① **도구 마일스톤** — 곡괭이 티어 1→2→3 달성 순간 채굴 가능 깊이·속도가 눈에 띄게 확장(테라리아식 "벽이 열리는" 감각).
  ② **건설 마일스톤** — 석빙고 모듈(승인 확정 5종) 하나를 완성할 때마다 밀폐도·거점 기능이 계단식 상승.
  ③ **압력 마일스톤** — 10일마다 더위 단계 +1로 낮 지상 제한이 강해지고 밤 습격 구성이 변화.
- **플레이어 선택 지점**: 낮 "안전한 상층 채집 vs 위험한 심층 도전", 밤 "증축 우선 vs 요격 우선", 자원 배분 "도구 강화 vs 벽 보강" — 세 갈래가 매일 반복되며 빌드 개성을 만든다.
- **30일차 = MVP 데모 엔딩**: 석빙고 **중간 완성 검증**(밀폐도 중간 목표 + 모듈 일부 완성 여부 평가) + 강철이 습격 시연. **백일폭염은 100일차**(정식 범위, 31~100일은 확장 문서 — 정본 1-8).

### 3-4. 리스크 1개 + 대비책
- **리스크**: 근접 호 판정 + 넉백 전투의 "손맛"(히트 피드백·튜닝)은 폴리시 비용이 커서 9일 내 미달 우려.
- **대비책**: 판정은 단순 부채꼴 1종으로 고정하고 곡괭이·무기가 스윙 코드를 공유해 개발 B의 구현량을 절반화(10장 D6~7 슬롯 내 수렴). 히트스탑·결빙 파티클은 아트 B의 기존 이펙트를 재활용하고, 손맛 튜닝이 밀리면 넉백 고정값 + 피격 점멸만으로 컷라인 방어.

### 4-4. 지하 진입 게이트 — 곡괭이 티어만 (시간 게이트 없음)
- **곡괭이(T1, 시작 지급)**: 흙·돌·석탄 고속, 철·구리는 저속 채굴 가능(소프트 게이트). 심층 경계 빙암(경도3)은 파괴 불가 → 심층 진입 차단.
- **강화 곡괭이(T2, 화로 + 철·구리)**: 철·구리 고속, 빙암·얼음강철·서리정수 채굴 가능 → 심층 해금(하드 게이트).
- **얼음강철 곡괭이(T3, 얼음 모루 + 얼음강철)**: 전 타일 고속·범위 채굴 — 21~30일 최종 구간 효율용.
- 규칙: 타일마다 경도 1~3, `곡괭이 티어 ≥ 경도`일 때만 파괴. 자원별 초/타일은 6-4 매트릭스.
- 심층 위험: 어둑시니 상주(빛 없으면 거대화) — 등불 없이 내려가는 것은 금지가 아니라 고위험 선택.

### 4-5. 콘텐츠 진행 구조
- **스테이지**: 10일 단위 = 더위 단계 +1 (MVP 3스테이지 = 30일, 정식 100일).
- **챕터(밤 습격 조합)**: 방망이 도깨비(1일~) → +불가사리(6일~) → +야광귀(11일~) → +어둑시니(16일~) → **강철이(30일차 데모 밤 클라이맥스 1회, 정식판 100일차 본체 — 3·6장 정합)**. 지하 해금은 일차와 무관, 곡괭이 티어로만.
- **최종 구간(구 "시즌")**: **21~30일차 — 밀폐도 100% + 핵심 모듈 5종 완공 도전** (2026-07-14 오너 승인 — 가안 해제. MVP 데모 엔딩, 정식판에선 91~100일차로 이식).

### 4-6. 시스템 의존 다이어그램 (순환)
주 순환: 낮 지하 채집(곡괭이 티어→채집 효율) → 광물·얼음 확보 → 제작대 승급·도구 티어 ↑ → 심층 해금 → 밤 증축 → 밀폐도 ↑ → 체온 유지 비용 ↓ → 더 깊은 채집 여유 ↑.
병렬 순환: 밤 요괴 처치 → 요괴 눈물·시그니처 드랍 → 설치물(등불·체·해태 석상)·특수 장치 제작 → 요괴별 카운터 확보 → 다음 밤 생존율 ↑ → 처치 수 ↑.

### 4-7. 판정 규칙 확정 / 엣지 케이스
- **화염 판정 공유 [메인 헤드 재정]**: 낮 태양 디버프·불가사리 화염 숨결·강철이 브레스는 전부 동일 "화염" 태그 — **해태 석상 반경 8타일 내 화염 피해 -50%** 하나로 전부 경감(구현 단일화).
- **등불 연료**: 석탄 1개 = 270초 점등(밤당 2개 소모). 반경 6타일 — 어둑시니 "받는 피해 2배" 판정 반경과 공유.
- **체(篩)**: 반경 4타일, 야광귀 12초 정지 + 받는 피해 1.5배, 쿨 30초.
- 순환 잠금 방지: T1 곡괭이로 철·구리 저속 채굴 허용 — 강화 곡괭이 재료 확보 경로를 항상 보장.
- 새벽 전환 시 지상 체류: 3장 도주 경고 후 낮 진입 즉시 화염 디버프 적용(체온 축과 정합).

## 9. 기술

### 기술: 유니티 9일 구현 명세 (최종본)
- **타일맵**: `Tilemap` + `TilemapRenderer`로 지상/지하 3레이어 구조, `ScriptableObject`로 16×16px 도트 타일셋(지상: 얼음/석빙고, 지하: 흙·돌/철·구리/얼음강철 — 정본 명칭) 관리.
- **낮밤 로직**: `TimeOfDayManager`로 **낮 900초/밤 540초** 사이클, `DayNightCycle`로 화염 디버프(1.5HP/sec) + 아지랑이 Shader 제어.
- **절차적 맵 생성**: `WorldGenerator(seed)` 4패스 — ①지형(1D 펄린 높이라인+레이어 경계·빙암) ②동굴(2D 펄린 공동, 깊을수록 10→25%) ③자원(6-4 빈도를 클러스터 광맥으로, CSV 수치 그대로) ④구조물(폐허·시작점 석빙고 터). 데모 빌드 시드 고정(심사·세이브 재현성), 맵 400×160타일, `CullingGroup` 렌더 최적화. 상세는 개발 명세서.
- **제작 트리**: `ScriptableObject`로 18종 레시피(6-5) 트리 정의, `CraftingStation`으로 재료 소모 + 결과 생성.
- **도구 티어**: 곡괭이(1티어) → 강화 곡괭이(2티어) → 얼음강철 곡괭이(3티어, 정본 4-1), 채집/파괴 효율은 6장 밸런스 표 기준, `UpgradeSystem`으로 인벤토리 강화 UI 연동.
- **세이브**: `SaveManager` — 전체 타일맵 대신 **시드 재생성 + 변경 타일 diff**만 JSON 직렬화(수 KB, 1초 내). 슬롯 3 + 새벽 오토세이브, 데모 세이브 3종(1·15·30일차, 시드 고정) 동봉으로 1-4 심사 시연 커버. 상세는 개발 명세서.
- **요괴 AI**: 요괴 5종(정본 4-1) — 방망이 도깨비·불가사리·어둑시니는 `FSM` Spawn→Approach→AttackWall→Flee, 야광귀는 Steal→Flee 분기, 강철이는 세그먼트 웨이브 보스(브레스 부채꼴 판정). **밤에만 스폰**, **새벽 3분 전 자동 경고 + 이동 속도 50% 감소**로 도주. 어둑시니 거대화는 스케일·알파 트랜스폼(8장), 등불 반경 6타일 판정은 광원과 공유(4-7).
- **우선순위**:
1) 타일맵+지하 생성(D1~2),
2) 낮밤+체온(D3),
3) 제작 트리+도구 티어(D4~5),
4) 요괴 AI+밀폐도 연동(D6~7),
5) HUD+인벤토리(D8),
6) 테스트/패치(D9).
- **리스크**: 지하+제작 트리 동시 로딩 → `Addressables`로 에셋 로드 분산, FPS 60 유지.
- **권장 스택**: Unity 2023.2 LTS, URP, Tilemap Extras, Cinemachine, Addressables.
