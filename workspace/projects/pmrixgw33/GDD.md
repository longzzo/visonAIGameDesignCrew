### 1-2. 핵심 훅 — "뒤집힌 낮밤" × "석빙고" × "테라리아 손맛"
낮=폭염으로 지상 불가, 밤=시원해 유일한 활동 시간이지만 도깨비 습격. 테라리아의 타일 파괴·제작·건설 손맛을 그대로 가져오되, "낮밤이 뒤집힌 생존"이라는 한 줄 차별점을 얹는다.

### 1-3. 코어 루프 (1일 = 24분)
낮 15분(지하 광물 채집·제작·도구 강화·석빙고 정비) → 밤 9분(지상 자원·석빙고 증축·도깨비 방어) → 10일마다 더위 단계 +1 → 30일 MVP 데모 엔딩 / 정식 100일 백일폭염.

### 1-4. 가안 (오너 승인 대기 — [가안] 유지)
| 항목 | 가안 | 근거 |
|---|---|---|
| [가안] 심사 시연 | 1일 24분이라 100일 실시간 불가 → **데모 세이브(1·15·30일차) + 개발빌드 배속키** | 심사 10~15분에 후반 긴장 체험 |
| [가안] 완공 조건 | 밀폐도 100% + 핵심 모듈 5종 | "완벽한 밀폐형"의 진행도 |

### 1-6. "테라리아 첫인상" 콘텐츠 폭 (MVP 확대 정의 — 오너 지시 반영)
MVP는 일수(30일)뿐 아니라 **다음 코어 콘텐츠가 돌아가야 "테라리아 같다"는 인상**이 난다:
1. **광물·타일 티어 3단계** — 흙·돌 / 철·구리 / 얼음강철(심층) — 깊이 내려갈수록 좋은 자원.
2. **제작 트리** — 작업대 → 화로 → 얼음 모루. 도구·차열벽·석빙고 모듈이 티어별로 해금.
3. **도구 업그레이드** — 곡괭이/설치도구 티어(채집 속도·범위 상승) — 진행감의 핵심.
4. **지하 탐험 깊이** — 지하 3레이어(상·중·심층), 아래로 갈수록 어둡고 위험하며 보상이 크다.
5. **적 다양성** — 도깨비 4종 전부 구현(방망이·불·정예·최종), 밤마다 조합 변화.
6. **건설 자유도** — 타일 자유 배치로 자기만의 석빙고 설계.

## 2. 세계관 (스토리 없음 — 환경 연출 전달)

**원칙: 컷신·대사·NPC 대화·텍스트 스토리텔링 없음. 모든 서사는 화면 연출(배경·스폰·오브젝트 변화)로만 전달한다 — 테라리아 방식.**

### 배경 — 백일폭염
태양이 날마다 커져 딱 100일 뒤 세계를 태워버리는 "백일폭염"이 온다. 낮의 지상은 화염처럼 뜨겁고, 밤만이 서늘하게 숨 쉴 수 있는 시간이다. 톤은 정본 그대로 — 공포가 아닌 **공포 없는 청량함과 역동적인 오싹함**, 여름밤 납량특집의 서늘한 재미.
- **인게임 표현**: 배경 태양 스프라이트가 더위 단계(10일)마다 실제로 커지고 하늘 팔레트가 청→주황→적으로 물든다. 낮 지상의 아지랑이 셰이더와 화염 디버프 이펙트가 "말 없이" 위험을 전달.

### 주인공 — 서리발톱
발톱에 서리가 맺힐 만큼 얼음 블록을 잘 다루는 고양이. 옛 조상들의 석빙고(石氷庫) 터를 밀폐형 기지로 완공하는 것이 유일한 생존법이다.
- **인게임 표현**: 대사 없음. 낮에는 헥헥거리는 idle 모션과 체온 바 상승, 밤에는 눈이 반짝이는 스프라이트로 전환 — 캐릭터 성격은 전부 모션으로만 전달.

### 주적 — 도깨비들
폭염 세상에서 가장 귀한 보물인 "냉기"를 노려 밤마다 몰려오는 한국 전통 도깨비. 무섭다기보다 **얄밉다**.
- **인게임 표현**: 불로 얼음을 녹이고 방망이로 벽을 때리는 행동 자체가 동기 설명. 새벽에 속도 50% 감소로 허둥지둥 퇴각하는 모습(9장 기술 명세와 동일)이 "얄미운 익살"의 핵심 연출.

### 연출 비트 (구 스토리 훅 — 전부 화면 연출로 대체)
1. **1일차 밤 (오프닝)** — 컷신 없음. 시작 지점 옆에 무너진 석빙고 폐타일 더미와 평소 2배 크기 태양을 배치. 플레이어가 첫 화면을 본 순간 "짓고 버텨야 한다"를 스스로 이해한다.
2. **10일차마다 (에스컬레이션)** — 태양 스프라이트 확대 + 하늘 팔레트 변경 + 도깨비 스폰 수·조합 강화(6장 곡선 준수). 숫자가 아니라 화면과 습격 압박으로 위기를 체감시킨다.
3. **30일차 데모 엔딩 / 정식 100일차** — 백일폭염 도래를 화면 전체 백열 화이트아웃으로 표현 → 밀폐도 100%이면 석빙고 내부의 서늘한 청색 화면 + 잠든 서리발톱 스프라이트로 전환. 텍스트는 "D-0" 한 줄뿐. (기존 배경·스프라이트·HUD 재활용 — 전용 컷신 시스템 불필요)

### 조선 민화풍 텍스처
석빙고는 조선 시대에 겨울 얼음을 여름까지 보관하던 실존 석조 얼음 창고다 — 경주 석빙고처럼 남아 있는 실물이 이 게임의 "밀폐형 기지"에 역사적 실감을 준다. 도깨비 또한 민화 속에서 사람을 골탕 먹이되 어딘가 어수룩하게 당하는 익살꾼으로 그려져 왔다. 이 두 전통이 8장 아트의 도트·석빙고 문양 타일셋과 맞물려, "납량 = 공포"가 아닌 "납량 = 여름밤의 서늘한 익살"이라는 정본 톤의 근거가 된다.

### 스코프 가드
이번 개정은 기존 설정의 재구성으로 신규 고유명사 없음. 모든 연출은 기존 오브젝트(배경 스프라이트·타일·스폰 로직·HUD) 재활용으로 구현하며, 5명·9일 내 추가 시스템 0개를 전제로 한다.

## 3. 게임플레이

### 3-1. 코어 루프 다이어그램 (1일 = 낮 15분 + 밤 9분 — 정본 1-3 순서 준수)
```
[낮 15분 | 폭염 — 지상 제한]
  지하 하강 → 광물 채집(곡괭이) → 제작대에서 제작·도구 강화 → 더 깊은 레이어 개척
      ↓
[밤 9분 | 시원함 — 지상 개방]
  지상 자원 수집 → 석빙고 증축·수리 → 도깨비 습격 방어 → 전리품(도깨비 눈물 등) 수거
      ↓
[성장 환류] 전리품·상위 광물 → 상위 도구/모듈 제작 → 다음 낮, 더 깊고 유리하게
```
10일마다 더위 단계 +1(정본) → 낮은 더 가혹해지고 밤 습격은 거세져 루프 압력이 우상향한다.

### 3-2. 핵심 메커니크
1. **지하 3레이어 — 자연 게이트 (시간 게이트 없음)**: 상층(흙·돌)·중층(철·구리)·심층(얼음강철)은 **처음부터 물리적으로 존재**하며 1일차에도 파고 내려갈 수 있다. 진입을 막는 것은 일수가 아니라 ① **곡괭이 티어** — 심층 얼음강철은 상위 곡괭이로만 채굴 가능(티어 3단계, 정본 1-6) ② **환경 위험** — 깊을수록 어둡고(광원 필요) 심층에는 정예 도깨비가 상주. "일찍 무리해서 내려가기"는 금지가 아니라 리스크 높은 플레이어 선택이다.
2. **제작 트리 — 작업대 → 화로 → 얼음 모루**: 해당 제작대 **근처에 서 있으면 낮밤 무관 언제든 제작 가능**(테라리아식). 상위 제작대가 상위 레시피(도구·차열벽·석빙고 모듈)를 해금하며, 제작대 자체를 어디에 놓을지가 거점 설계의 일부다.
3. **전투 루프 (테라리아식 근접)**: 곡괭이/무기 휘두르기 = **전방 근접 호(arc) 판정** → 명중 시 **넉백**으로 거리 확보 → 처치 시 **드랍(도깨비 눈물 등 종별 재료)** → 얼음 모루의 특수 레시피(차열벽 강화·석빙고 모듈 부품)로 환류. 곡괭이와 무기는 동일 스윙 로직을 공유한다. ※ 데미지·넉백 거리·드랍률 등 수치는 6장 밸런스 확정 사항.
4. **도깨비 4종 출현 로직 (정본 명칭)**: **방망이**(기본형, 1일차 밤부터 — 벽 타격) / **불**(중반 합류 — 얼음 타일 용해로 건설을 위협) / **정예**(심층 상주 경비 + 후반 밤 지상 합류) / **최종**(30일차 데모 밤의 클라이맥스 습격, 정식판에서는 100일차 보스). 밤 스폰 수는 정본 공식 **min(8, 1+floor((Day-1)/4))** 만 사용. 종별 합류 일차의 세부 수치는 6장 밸런스 소관.

### 3-3. 세션 설계 (24분 × 30일 MVP)
- 진행 체감은 시간제 퀘스트·수집 이벤트가 아닌 **유기적 마일스톤** 3축으로 만든다:
  ① **도구 마일스톤** — 곡괭이 티어 1→2→3 달성 순간 채굴 가능 깊이·속도가 눈에 띄게 확장(테라리아식 "벽이 열리는" 감각).
  ② **건설 마일스톤** — 석빙고 모듈([가안] 5종) 하나를 완성할 때마다 밀폐도·거점 기능이 계단식 상승.
  ③ **압력 마일스톤** — 10일마다 더위 단계 +1로 낮 지상 제한이 강해지고 밤 습격 구성이 변화.
- **플레이어 선택 지점**: 낮 "안전한 상층 채집 vs 위험한 심층 도전", 밤 "증축 우선 vs 요격 우선", 자원 배분 "도구 강화 vs 벽 보강" — 세 갈래가 매일 반복되며 빌드 개성을 만든다.
- **30일차 = MVP 데모 엔딩**: 석빙고 **중간 완성 검증**(밀폐도 중간 목표 + 모듈 일부 완성 여부 평가) + 최종 도깨비 습격 시연. **백일폭염은 100일차**(정식 범위, 31~100일은 확장 문서 — 정본 1-8).

### 3-4. 리스크 1개 + 대비책
- **리스크**: 근접 호 판정 + 넉백 전투의 "손맛"(히트 피드백·튜닝)은 폴리시 비용이 커서 9일 내 미달 우려.
- **대비책**: 판정은 단순 부채꼴 1종으로 고정하고 곡괭이·무기가 스윙 코드를 공유해 개발 B의 구현량을 절반화(10장 D6~7 슬롯 내 수렴). 히트스탑·결빙 파티클은 아트 B의 기존 이펙트를 재활용하고, 손맛 튜닝이 밀리면 넉백 고정값 + 피격 점멸만으로 컷라인 방어.

### 4-4. 지하 진입 게이트 — 곡괭이 티어만 (시간 게이트 삭제)
- **곡괭이(T1, 시작 지급)**: 흙·돌 고속 채굴, 철·구리는 저속 채굴 가능(소프트 게이트). 심층 경계 빙암(경도3)은 파괴 불가 → 심층 진입 차단.
- **강화 곡괭이(T2, 화로 + 철·구리)**: 철·구리 고속, 빙암·얼음강철 채굴 가능 → 심층 해금(하드 게이트).
- **얼음강철 곡괭이(T3, 얼음 모루 + 얼음강철)**: 전 타일 고속·범위 채굴 — 21~30일 최종 구간 효율용.
- 규칙: 타일마다 경도 1~3, `곡괭이 티어 ≥ 경도`일 때만 파괴. 채굴 속도 배수는 6장 밸런스 변수.

### 4-5. 콘텐츠 진행 구조
- **스테이지**: 10일 단위 = 더위 단계 +1 (MVP 3스테이지 = 30일, 정식 100일).
- **챕터(밤 습격 조합)**: 방망이(1일~) → +불(6일~) → +정예(16일~) → **최종(30일차 데모 밤 클라이맥스 1회, 정식판 100일차 보스 — 3·6장 정합)**. 지하 해금은 일차와 무관, 곡괭이 티어로만.
- **최종 구간(구 "시즌")**: **21~30일차 — 밀폐도 100% + 핵심 모듈 5종[가안] 완공 도전** (MVP 데모 엔딩, 정식판에선 91~100일차로 이식).

### 4-6. 시스템 의존 다이어그램 (순환)
주 순환: 낮 지하 채집(곡괭이 티어→채집 효율) → 광물·얼음 확보 → 제작대 승급·도구 티어 ↑ → 심층 해금 → 밤 증축 → 밀폐도 ↑ → 체온 유지 비용 ↓ → 더 깊은 채집 여유 ↑.
병렬 순환: 밤 도깨비 처치 → 눈물 드랍 → 특수 장치 제작 → 밀폐도·방어 보강 → 다음 밤 생존율 ↑ → 처치 수 ↑.

### 4-7. 밸런스 위임 변수 / 엣지 케이스
- 변수: V_기본·V_정예·V_최종(눈물 드랍량), 경도별 채굴 속도 배수, 철근 폐허 스폰 밀도, 특수 장치 재료비, 체온 증감률.
- 순환 잠금 방지: T1 곡괭이로 철·구리 저속 채굴 허용 — 강화곡괭이 재료 확보 경로를 항상 보장.
- 새벽 전환 시 지상 체류: 3장 도주 경고 후 낮 진입 즉시 화염 디버프 적용(체온 축과 정합).

## 8. 아트

### 8-1. 방향 판정 — "조선 민화풍" 채택 (메인 헤드 추천안 승인, 조건부 발전)
- **판정: 타당, 채택.** 근거 3가지: ① 민화의 평면 채색+굵은 먹선은 도트 아트의 외곽선·제한 팔레트 문법과 1:1 호환(변환 비용 최소), ② 호작도·민화 도깨비의 "무섭지 않고 얄미운" 익살은 정본 톤 "공포 없는 청량함"과 정확히 정합, ③ 오방색은 티어/기능 색 코딩 체계로 그대로 전용 가능. 대안으로 검토한 수묵담채는 번짐·농담 표현이 16×16px에서 전부 소실되어 기각, 일반 "조선풍(기와·한복 소품 나열)"은 정체성이 배경 소품에 머물러 기각.
- **채택 조건 3개(16px 가독·물량 한계 반영)**: 호작도 줄무늬는 등·꼬리에 2~3px 획으로 축약 / 단청 문양은 석빙고 모듈 타일 상단 2px 머리초 띠로만(전면 단청은 물량 초과) / 오방색은 포인트 전용, 주조는 청량 톤 유지.

- 도트, 타일 16×16px 고정. 모든 스프라이트에 1px 먹선(#1A1A24) 외곽 — 민화 먹선의 도트 번역이자 폭염·설원 어느 배경에서도 실루엣을 분리하는 가독 장치.

## 9. 기술

### 기술: 유니티 9일 구현 명세 (최종본)
- **타일맵**: `Tilemap` + `TilemapRenderer`로 지상/지하 3레이어 구조, `ScriptableObject`로 16×16px 도트 타일셋(지상: 얼음/석빙고, 지하: 흙·돌/철·구리/얼음강철 — 정본 명칭) 관리.
- **낮밤 로직**: `TimeOfDayManager`로 **낮 900초/밤 540초** 사이클, `DayNightCycle`로 화염 디버프(1.5HP/sec) + 아지랑이 Shader 제어.
- **지하 생성**: `PerlinNoise` + `Tilemap.SetTile`로 지하 3레이어 생성, `CullingGroup`으로 렌더링 최적화.
- **제작 트리**: `ScriptableObject`로 12종 아이템 트리 정의, `CraftingStation`으로 재료 소모 + 결과 생성.
- **도구 티어**: 곡괭이(1티어) → 강화 곡괭이(2티어) → 얼음강철 곡괭이(3티어, 정본 4-1), 채집/파괴 효율은 6장 밸런스 표 기준, `UpgradeSystem`으로 인벤토리 강화 UI 연동.
- **도깨비 AI**: 방망이·불·정예·최종 도깨비 4종(정본 명칭), `FSM`으로 Spawn→Approach→AttackWall→Flee, **밤에만 스폰**, **새벽 3분 전 자동 경고 + 이동 속도 50% 감소**로 도주.
- **우선순위**:
1) 타일맵+지하 생성(D1~2),
2) 낮밤+체온(D3),
3) 제작 트리+도구 티어(D4~5),
4) 도깨비 AI+밀폐도 연동(D6~7),
5) HUD+인벤토리(D8),
6) 테스트/패치(D9).
- **리스크**: 지하+제작 트리 동시 로딩 → `Addressables`로 에셋 로드 분산, FPS 60 유지.
- **권장 스택**: Unity 2023.2 LTS, URP, Tilemap Extras, Cinemachine, Addressables.
